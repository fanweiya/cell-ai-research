# FreeBridge

> 利用仅终点数据，通过薛定谔桥模型单细胞扰动响应。

FreeBridge 是一个机器学习框架，用于模拟单个细胞对扰动的响应变化。它仅需对照和扰动后的细胞群体数据，无需追踪细胞随时间的个体轨迹。该系统将细胞状态定义与状态间的转换动力学相分离。

## 技术栈

- **Python** 3.10+（编程语言）
- **PyTorch** 未知（框架）
- **Hydra** 未知（配置）

## 核心功能

- 基于薛定谔桥公式的细胞转换动力学建模
- 仅需终点数据
- 支持在数据流形上保持中间状态的成本
- 细胞引擎架构，实现状态与转换的分离
- 支持 BBBC021、RxRx1 和 JUMP 数据集

## 快速开始

1. 克隆仓库
2. 使用 `pip install -e .` 安装依赖
3. 下载 BBBC021 数据集
4. 运行 `data_prep/` 目录下的数据准备脚本
