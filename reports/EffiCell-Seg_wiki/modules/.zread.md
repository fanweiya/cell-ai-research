# .zread

> 维护项目文档的元数据索引和页面导航结构。

.zread 模块是一个文档生成框架的核心配置部分，负责定义和索引项目的所有文档页面。它通过 JSON 格式存储文档的元数据，包括唯一标识符、生成时间、语言、页面标题、slug、关联文件、所属章节和难度级别。该模块不直接参与细胞分割算法的实现，而是作为文档管理系统的骨架，支持自动化文档生成、导航构建和版本控制。

## Files

### `wiki/drafts/wiki.json`

存储项目文档的完整索引列表，定义每个页面的元数据。

- `pages` (array) - 包含所有文档页面的数组，每个元素定义一个页面的 slug、标题、关联文件、章节和难度级别。
- `id` (string) - 文档索引的唯一标识符，通常基于时间戳生成。
- `generated_at` (string) - 文档索引生成的 ISO 8601 时间戳。
- `language` (string) - 文档的主要语言代码，如 'en'。

## Key Concepts

- **文档索引**: 将分散的 Markdown 文档组织成结构化的 JSON 索引，便于程序化读取和导航。
- **slug 路由**: 使用 URL 友好的 slug 作为页面的唯一标识，支持静态网站生成器的路由映射。
- **章节分级**: 通过 section 和 level 字段对文档进行分类和难度分级，优化用户阅读路径。
