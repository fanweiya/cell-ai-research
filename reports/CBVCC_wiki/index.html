CBVCC


> 用于分类活体显微镜细胞行为视频的指标与工具。


本项目为细胞行为视频分类挑战赛（CBVCC）提供指标和分析工具。它帮助研究人员构建模型，根据细胞运动模式对视频进行分类，具体识别突然的方向变化与持续的线性运动或静止细胞。


技术栈


  • Python 3.10+（编程语言）

主要功能


  • 根据数据集文件夹结构生成真实标签
  • 计算视频质量指标，如信噪比（SNR）和细胞轨迹计数
  • 通过 ROC 曲线和性能图表评估挑战赛提交结果

快速开始


  • 使用 git clone https://github.com/rcabini/CBVCC.git 克隆仓库
  • 使用 conda env create -f environment.yml 创建虚拟环境
