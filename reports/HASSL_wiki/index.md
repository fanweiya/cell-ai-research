# HASSL

> 基于 DINOv3 构建的、面向单细胞显微图像的层级感知自监督学习框架。

HASSL 旨在解决从生物细胞图像中学习有效表征的挑战，其中粗粒度的成像因素往往掩盖了精细的形态学信号。该框架引入了两个核心组件：一是双教师蒸馏方法，同时使用标准图像教师和网络分割教师，以引导模型关注细胞形态；二是层级感知对比损失，利用 HDBSCAN 构建聚类树，在每一层级上将细胞向其祖先质心拉近，同时将其与不同子类型推开。

该框架在包含 208 个细胞类别的 20 个显微数据集的 230 万个单细胞图像上进行了训练。与最先进的自监督学习基线相比，它取得了显著改进：平均 Top-K 准确率提升 2.8%，深层层级基准测试中的 Top-9 检索提升 6.3%，药物扰动分类的 F1 分数提升 7.8%。由此得到的潜在空间将细胞组织成具有更清晰形态驱动子簇的超级簇。

## 技术栈

- **Python** 3.11（编程语言）
- **PyTorch** 2.10.0（框架）
- **DINOv3** 最新版（模型）
- **HDBSCAN** 0.8.41（库）
- **Weights & Biases** 0.25.0（工具）

## 核心功能

- 采用分割教师的双教师蒸馏
- 基于 HDBSCAN 的层级感知对比损失
- 支持跨 208 个细胞类别的 230 万张单细胞图像
- 改进的形态学表征与更紧密的子簇
- 与 DINOv3 主干网络集成

## 快速开始

1. 克隆仓库并创建 conda 环境：`conda env create -f conda.yaml`
2. 激活环境：`conda activate dinov3`
3. 设置 Weights & Biases 环境变量：`export WANDB_ENTITY='<your-wandb-entity>'`
4. 准备训练清单：下载数据集或使用提供的数据集
