# docs

> 提供 HASSL 项目的静态展示页面，用于介绍方法、作者和引用信息。

该模块包含一个 HTML 页面，作为 HASSL 项目的官方展示窗口。它使用现代 CSS 和 Google Fonts 构建响应式布局，包含英雄区域（Hero Section）、作者列表、机构归属、项目链接（如论文、代码、数据集）以及引用信息。页面通过内联样式定义主题色和布局，不依赖外部 CSS 框架，确保加载速度和一致性。

## Files

### `docs/index.html`

渲染 HASSL 项目的主页，展示方法概述、作者、引用和外部链接。

- `hero` (section) - 页面顶部的英雄区域，包含标题、副标题、会议徽章和主要操作按钮。
- `authors-section` (section) - 展示作者列表及其所属机构编号，支持上标引用和等贡献标记。
- `logos-bar` (section) - 显示合作机构或资助方的标志栏（代码被截断，但意图明确）。
- `btn` (class) - 通用按钮样式类，支持悬停效果和图标集成。
- `btn-primary` (class) - 主按钮样式，使用强调色背景。
- `btn-outline` (class) - 轮廓按钮样式，用于次要操作。
