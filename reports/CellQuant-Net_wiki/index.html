CellQuant-Net


> 一种用于全切片图像中细胞核检测、分类和质量评估的流水线。


CellQuant-Net 是一款计算病理学工具，旨在检测并对 H&E 染色的全切片图像中的细胞核进行分类。它采用一种名为 CP-Net 的轻量级网络，专注于血红蛋白通道以高效学习细胞核特征。与更重的模型相比，该方法在保持跨不同器官和扫描仪准确性的同时，减少了推理时间。


该流水线包含一个质量评估（QA）模块，用于过滤掉包含模糊或褶皱等伪影的低质量图像切片。经过 QA 处理后，CP-Net 会对剩余的切片进行处理以识别细胞核。该系统还会计算细胞核连通性指标，从而提供关于肿瘤微环境的定量数据。


用户只需将全切片图像（WSI）放入输入文件夹并提供预训练权重，即可在自己的 WSI 上运行此工具。结果（包括合格的切片和汇总统计信息）将保存在输出目录中。


技术栈


  • Python 3.9（编程语言）
  • PyTorch 2.x（框架）
  • MONAI 1.3.0（库）
  • OpenSlide 1.1.2（库）
  • CUDA 12.8（GPU）

核心功能


  • 采用 CP-Net 轻量级架构，实现快速细胞核检测
  • 质量评估模块，可排除含伪影的切片
  • 支持多种公共和私有数据集
  • 细胞核连通性分析，提供定量指标
  • 端到端流水线，从 WSI 输入到结果输出

快速开始


  • 将仓库克隆到您的系统。
  • 运行 chmod +x install.sh，随后执行 ./install.sh 以安装依赖项。
  • 通过 conda activate cellquantnet 激活 conda 环境。
  • 运行 python verify_installation.py 验证安装是否成功。
  • 下载预训练模型权重，并将 CP-Net 权重放入 CP-Net/weights/，将 WSI-QA 权重放入 WSI_QA/pretrained_ckpt/。
