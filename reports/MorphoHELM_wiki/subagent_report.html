项目概述


MorphoHELM 是微软推出的 Cell Painting 表征评测基准框架，对应论文 *"MorphoHELM: A Comprehensive Benchmark for Evaluating Representations for Microscopy-Based Morphology Assays"* (arXiv 2605.15383)。核心目标是建立统一的 Cell Painting 表征评测标准，跨数据集和任务比较经典形态特征（CellProfiler）与深度模型（DINOv2、ResNet、CLOOME等），并发现没有一种深度表征能在所有任务上占优。


主要解决的问题：

  • Cell Painting 表征方法碎片化，缺乏统一评测框架
  • 不同数据集（CPG0016、BBBC036）和任务（MoA分类、CRISPR富集、复现性分析）间难以公平比较
  • 深度模型与经典方法的系统性对比缺失

主要模块

  • 数据安装：下载公开原始图像→光照校正→保存为uint8 PNG
  • HuggingFace转换：将校正后图像转为HF数据集格式
  • 特征提取：支持8种模型（DINOv2、ResNet、VGG19、OpenPhenom、CLOOME、SubCell）
  • 聚合：将多GPU推理结果聚合为well-level parquet
  • 标准化：Plate-level CenterScale → PCA → MAD稳健化
  • 基准测试：MoA富集、CRISPR富集、kNN复现性、mAP评估

依赖关系

  • 核心：numpy, pandas, pyyaml, Pillow, scipy, scikit-learn
  • ML框架：torch, torchvision, transformers, timm, datasets
  • 数据加载：HuggingFace cellpainting_huggingface_loader（本地包）

核心算法


1. 光照校正算法

def correct_cpg0016_to_uint8(image, illumination):
    corrected = image / illumination  # 逐像素除法
    vmin, vmax = np.percentile(corrected, (0.05, 99.95))
    corrected = (corrected - vmin) / (vmax - vmin)  # 百分位对比度拉伸
    return to_uint8(corrected)
  • 对CPG0016使用百分位裁剪（0.05%和99.95%）
  • 对BBBC036使用全范围归一化
  • 两者最终转换为uint8 PNG

2. 多模型统一接口

所有模型继承 ModelWrapper基类：

class ModelWrapper:
    def _load_model(self): abstract
    def infer(self, data_input): abstract
    def postprocess(self, data_input, model_output): abstract
  • 支持单通道模型（DINOv2、ResNet）和多通道模型（CLOOME、SubCell）
  • 单通道模型将单通道重复3通道并应用ImageNet标准化
  • 多通道模型保持5通道原样，使用特定预处理

3. 特征聚合策略

根据模型类型采用不同聚合方式：

  • 单通道模型：按(plate, well, fov, channel)平均→跨通道拼接
  • OpenPhenom：按(plate, well, fov)平均
  • CLOOME/SubCell：按(plate, well)平均（5通道已堆叠）

4. 标准化流程

默认配置：CSAll_Plate__PCA64__MADCtrl_Plate__NoSph

  • Plate-level CenterScale：每块板内所有细胞归一化
  • PCA降维：64个主成分
  • MAD稳健化：基于对照样本的Median Absolute Deviation标准化
  • 不球化（NoSph）

    _load_model()
    infer(data_input)
    postprocess(data_input, model_output)
  • 可参考此模式包装你的YOLO和SAM模型

  • 将自定义细胞图像转为HF数据集格式，统一数据加载接口

3. 多GPU推理架构

  • run_inference.py的多进程spawn逻辑，适合大规模批处理

  • 5%细胞计数QC阈值策略可借鉴

❌ 基准定义：Bioactivity/CRISPR富集任务与你的目标不同

❌ 数据格式：CPG0016/BBBC036的具体元数据不适用于你的数据集
