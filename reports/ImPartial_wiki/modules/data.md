# data

> 管理基于部分标注的交互式实例分割框架的数据加载与数据集结构

该模块负责定义和加载自定义数据集，支持部分标注场景。核心是Vectra_WC_2CH_tiff数据集，通过JSON文件描述图像与标注的映射关系，标注以ZIP压缩包形式存储。模块提供数据索引、路径解析和元数据管理功能，为训练和推理提供数据支撑。

## Files

### `data/README.md`

文档说明数据集结构

### `data/Vectra_WC_2CH_tiff/datastore_v2.json`

定义数据集元数据，包含图像路径、标注路径及校验信息

## Key Concepts

- **部分标注**: 数据集中部分图像拥有完整标注，部分图像无标注，支持半监督学习场景
- **ZIP标注格式**: 标注文件以ZIP压缩包存储，包含实例分割的掩码和类别信息
- **数据索引**: 通过JSON文件建立图像与标注的映射关系，支持快速检索和验证
