边界感知实例分割


> 通过预测有符号距离函数并利用边界感知损失，分割显微图像中的单个细胞。


本项目实现了一个用于显微图像实例分割的框架。模型不预测二值掩码，而是输出代表细胞轮廓几何形状的有符号距离函数（SDF）。一个学习到的 sigmoid 函数将这些 SDF 预测转换为概率图和软边界。


训练过程使用三个损失组件：sigmoid 输出的交叉熵、SDF 本身的均方误差，以及一个直接惩罚边界不对齐的改进型豪斯多夫距离项。这种组合有助于比基于掩码的标准方法更准确地分离接触或重叠的细胞。


技术栈


  • Python 3.10+（编程语言）
  • PyTorch 1.12.1（框架）
  • PyTorch Lightning 2.1.4（框架）
  • MONAI 1.3.2（库）
  • YAML 6.0（配置文件）

核心功能


  • 基于 SDF 的表示，用于平滑的细胞轮廓建模
  • 学习到的 sigmoid 映射，将 SDF 转换为分割概率
  • 用于分离接触实例的边界感知改进型豪斯多夫距离损失
  • 无需提示的显微图像分割框架
  • 基于 YAML 的配置，用于实验管理

快速开始


  • 克隆仓库并进入项目目录。
  • 创建包含 Python 3.10 的 conda 环境并激活它。
  • 使用 pip install -r requirements.txt 安装依赖项。
