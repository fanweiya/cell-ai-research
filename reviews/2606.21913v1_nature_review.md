## 审稿人 1

**总体评估** 该手稿提出 EffiCell-Seg，一个基于冻结视觉基础模型（DINOv3）的细胞实例分割适配框架。其核心机制将细胞结构提示编码器（CSP-Encoder）——通过 CLS-空间 token 余弦相似度提取显著性、通过 top-K PCA 提取形态变异——与协同掩码解码器（SM-Decoder）相结合，后者在几何距离查询与语义查询之间采用双向交叉引导。尽管参数效率值得注意（499 万可训练参数，而先前基线超过 5000 万），但架构公式化存在数学疏漏、关于空间 token 空间中 PCA 语义的机制性主张缺乏支撑、且缺少在线 PCA 推理时的计算复杂度细节。

**谁会对结果感兴趣，为什么** 计算病理学、生物医学计算机视觉及基础模型适配领域的研究人员——尤其是寻求面向密集生物医学实例分割的轻量级参数高效微调（PEFT）范式者。

**主要优点**
1. 在完全冻结重型基础模型编码器的前提下，实现了清晰的参数效率缩减（499 万可训练参数）。
2. 概念上优雅地将全局定位（CLS token 余弦相似度）与局部形态（空间 token 变异）解耦。
3. 在 CellSeg 和 DSB 两个基准上的语义指标（Dice、mIoU）与实例指标（PQ、F1）均取得一致的实证性能提升。

**重大关切**

- **Concern ID** R1-M1
- **严重度** Major
- **是否阻断** 是
- **评估轴** 技术可靠性 / 数学公式化
- **主张指针** 第 2.2 节，公式 3："we apply PCA to {t_i}_{i=1}^N and retain the top-K components... m_i = PCA_K({t_i}_{i=1}^N) in R^K"
- **证据指针** 第 2.2 节中描述前向传播期间对每张图像 patch token 执行 PCA 的段落
- **关切** 在线 patch 级 PCA 的公式化含糊不清，且在批处理尺度上可能不可微或计算开销过高。具体而言，PCA 究竟是逐张图像拟合、按批次拟合，还是从静态全局校准集离线预计算，并不明确。若在前向传播中逐单张图像计算，对空间 token 协方差矩阵的特征分解（例如 512×512 输入、16×16 或 8×8 patch 时 N=1024 或 4096）会引入符号歧义（特征向量符号可任意翻转 ±v），除非显式强制规范方向或空间投影，否则将破坏跨图像与跨批次的特征一致性。
- **为何重要** 不同样本间 PCA 特征向量的符号翻转会使形态先验图 z_i 的极性反转，从而损害 CSP-Encoder 中卷积适配器的学习，导致训练不稳定或推理崩溃。
- **解决测试** 明确 PCA 是离线预计算还是在线动态计算。若为在线计算，需给出显式算法以解决特征向量符号歧义，并基准测试推理期间 SVD/PCA 引入的确切运行时延迟 / FLOPs 开销。

- **严重度** Major
- **是否阻断** 是
- **评估轴** 技术可靠性 / 架构消融
- **主张指针** 第 2.3 节，公式 5："h_g <- CrossAttn(q_g, q_g, h_g + h_s), h_s <- CrossAttn(q_s, q_s, h_g + h_s)"
- **证据指针** 第 2.3 节与第 3.3 节（表 3）

## 交叉综合（审稿后汇总；未呈现给各位审稿人）

**共识优点**
1. 高参数效率（499 万可训练参数，而现有基础模型适配器为 5000 万至 6.8 亿）。
2. 冻结编码器范式可防止灾难性遗忘，并大幅降低微调算力需求。
3. 在两个基准数据集（CellSeg 与 DSB）上观察到扎实的实证性能提升。

**共识阻断性问题**
1. **统计报告与显著性（R2-M1、R1-M2）**：相对 SAC 的报告优势（Dice/mIoU 不足 1%）缺乏重复运行、置信区间与假设检验。在未证明统计显著性的情况下，"超越 SOTA"的主张未经验证。
2. **数学 / 在线 PCA 一致性（R1-M1）**：在线 patch-token PCA 提取未显式处理跨前向传播与跨批次下的特征向量符号歧义，存在特征融合阶段表示不稳定的风险。
3. **分布外泛化（R3-M1）**：跨多模态细胞成像稳健泛化的主张仅在两个传统数据集的标准分布内划分上进行了检验。需要跨数据集零样本评估（如 LIVECell 或 TissueNet）。
4. **基线后处理不对称（R2-M2）**：实例分割（PQ/F1）的性能差距可能被后处理启发式差异（分水岭距离场回归 vs SAM 网格提示过滤）所混杂。

**其他共识重大关切**
1. **失效模式刻画（R3-M2）**：缺乏定量错误分解（不同汇合度与噪声水平下的过分割 vs 欠分割）。
2. **对称交叉注意力坍缩风险（R1-M2）**：无约束的双向相加可能导致几何与语义嵌入之间的表示同质化。

**各审稿人的侧重点差异**
- **审稿人 1** 主要关注架构有效性、在线 token PCA 的数学公式化以及 transformer 查询表示动力学。
- **审稿人 2** 重点审视统计报告严谨性、置信区间缺失、指标差值的边际性与基线归一化的公平性。
- **审稿人 3** 强调生物学领域相关性、跨多样显微平台的分布外泛化能力，以及面向最终用户的透明失效模式分类。

**小修清单**
1. 写明 PCA 形态分量提取中超参数 K 的确切取值（R1-m1）。
2. 给出确切的分水岭阈值参数，并核实所有基线的后处理一致性（R1-m2）。

**广泛兴趣 / 重要性判读**
该手稿提出了一个有价值的参数高效微调（PEFT）框架，可用于在生物图像信息学中部署视觉基础模型。然而，要使这项工作从一篇渐进式工程论文跃升为 Nature Methods 或 Nature Machine Intelligence 级别的高影响力发表，作者必须证实其机制性主张、证明分布外的生物学稳健性，并采用严格的统计报告标准。

**确立强力 Nature 级结论之前最需要解决的问题**
1. 开展 5 折交叉验证或多种子试验，报告均值±标准差以及相对 SAC 与 CellViT 的配对 p 值。
2. 从数学上解决 PCA 特征向量符号歧义，并为在线 SVD 提供运行时性能剖析。
3. 补充在 LIVECell 或 TissueNet 上的零样本跨数据集评估。
4. 提供后处理启发式的消融实验，将表示学习与分水岭过滤的收益解耦。

**风险 / 无支撑主张**
- "DINOv3 的结构知识可在多样的细胞成像模态间普适重对齐"这一主张，仅在两个特定分布内基准划分之外得不到支持。
- 由于缺乏针对不足 1% 指标差异的统计假设检验，"优于 SAC 的 SOTA"这一主张目前不受支持。
