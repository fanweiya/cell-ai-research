# Cell AI Copilot 交互改版与项目检查

## 本次实现

- 论文标题旁增加「AI 解读」，带入单篇论文、聚焦输入框，不自动调用模型。
- 论文勾选与收藏独立；批量操作条支持「对比 / 提问」。
- Copilot 支持全库、指定论文、搜索添加、收藏筛选、使用当前页面筛选、移除论文。
- 选择弹窗使用临时选择，取消不更改当前讨论。
- 指定模式可额外检索最多 4 篇相关研究，使用现有摘要和标签的关键词匹配；不是语义检索。
- 每条用户消息记录发送时的输入范围及论文清单，范围改变只影响下一次请求。
- 全库模式仍发送全部摘要。输入清单不代表模型已逐篇比较或回答中的每个结论均经验证。
- 支持标准 Markdown 表格、带空行/转义首列的表格、代码块与安全链接；表格可横向滚动。
- 支持单请求防重入、停止、180 秒超时、失败恢复问题和范围、输入法组合回车保护。
- 手机全屏，桌面可展开。关闭侧栏后不可通过键盘进入隐藏控件。

## 维护与预览

Copilot 源文件位于 `web/copilot.html`、`web/copilot.css`、`web/copilot.js`。
生成器把这些文件内联到 `index.html`，所以仍是纯静态页面，无数据库、无新增部署依赖。
不要只编辑最终 HTML，下次流水线生成会覆盖。

```powershell
python generate_index.py --offline
python -m http.server 8768 --bind 127.0.0.1
```

`--offline` 不调用模型、不下载图片、不检查 arXiv 链接；使用现有数据和缓存。
正常每日流水线行为不变。

前端行为测试依赖 Node.js 与 jsdom（本次安装在工作区临时目录，没有修改全局依赖）：

```powershell
$env:NODE_PATH='C:\workspace\tmp\cell-copilot-ui-test\node_modules'
node --test tests/copilot.test.cjs
```

## 后续值得优先处理的项目

| 优先级 | 观察到的问题 | 建议 |
|---|---|---|
| 高 | 全库摘要每次约 11 万 Token，增长后会更大 | 下一阶段做全库短卡片与按需补充证据；不要悄悄截断或把 top-k 冒充全库覆盖 |
| 高 | 浏览器直接调用公开 AI 网关，当前请求代码不带认证 | 核查网关服务端现有鉴权和额度控制；仅凭页面不能判定网关是否无保护，不要把密钥放进 HTML |
| 高 | AI 摘要、代码报告和论文原文的证据级别不同 | 为结论增加来源类型、章节/段落和生成时间；指标应能追溯到原始材料 |
| 中 | 页面包含量子霍尔、服装生成等明显跨出细胞主题的标题 | 人工核查入库规则和任务相关性，保留可借鉴方法类的明确标签，不自动删除现有记录 |
| 中 | 生成 HTML 约 5.7 MB，324 篇卡片一次进入 DOM | 后续将摘要数据分离并按需加载，考虑列表分段渲染，同时保留搜索与深链接能力 |
| 中 | 标题要点已有内容，但有些研究状态仍为待处理 | 分开表示翻译摘要完成、研究评审完成、代码静态分析完成、实际复现通过 |
| 中 | 对话刷新后丢失 | 可增加用户可控的本地会话保存、导出和新对话；这次未自动持久化研究问题 |
| 中 | 项目有大量未跟踪文件，Git 未配置远端 | 先区分源码、发布产物、缓存和研究数据，再建立版本管理与回滚策略；不要批量清理或提交 |
| 低 | `.planning/implementation-plan.md` 内容是视频制作技能，与本项目不符 | 确认归属后迁移，避免后续开发误读；本次没有执行或修改其中的指令 |

范围：本次完成的是 Copilot UI 和渲染修复，不是对全部论文科学结论或网关安全的完整审计。

## 原文证据接入与后续简化

- 已移除卡片收藏、侧栏收藏、Copilot 收藏范围及相关 localStorage 逻辑；不删除浏览器旧存储。
- 已移除研究/工程评分、优先级展示、未评分筛选，以及研究评审标签；原始 papers.json 数据保留。
- 列表首批 30 篇，接近底部时 IntersectionObserver 自动加载下一批，自动加载不抢焦点；搜索与 Copilot 范围仍覆盖全部匹配项。
- evidence_export.py 为当前 324 篇导出静态原文缓存 JSON，按内容哈希命名，页面只内嵌路径；publish_cf_pages.sh 同步这些文件。
- 历史原文缓存来自 HTML 章节提取或 PDF 文本，旧采集器最多保留 60000 字符。全部缓存不等于完整论文，界面和提示词明确这一限制；未重爬全部原文。
- 单篇优先读取全部缓存；多篇/全库最多补读 8 篇，原文预算合计 72000 字符，超过预算按关键词选片段，保留片段顺序。关键词采用中英文扩展，尚非向量检索。
- 每次请求记录论文范围、实际原文片段、完整缓存/部分选读状态和下载失败情况。4 路并发读取，15 秒单文件超时，24 份浏览器内存缓存；停止按钮覆盖原文读取及模型调用。
- 精简回答要求，不强制凑事实/推断/假设目录及三个追问；未确认代码链接不等于无开源。引用展示按已知论文 URL 规范化编号，未读取的段号标记未匹配；这不是科学结论的自动验证。
- 修复数值/常见 HTML 字符实体、嵌套列表和代码内竖线表格分隔，解码后仍做 HTML 转义并限制链接协议。
