III Method III-A Problem Formulation In the weakly supervised MIL setting, each WSI is treated as a bag, and its patches are treated as instances. The training set is given as a weakly labeled set S := { ( B i , Y i ) } i = 1 N S:=\{(B_{i},Y_{i})\}_{i=1}^{N} , where each bag B i := { x i 1 , x i 2 , … , x i n i } B_{i}:=\{x_{i}^{1},x_{i}^{2},\ldots,x_{i}^{n_{i}}\} is associated with an observed bag-level label Y i Y_{i} , and the instance-level labels are not observed. Let 𝒞 := { 1 , 2 , … , C } \mathcal{C}:=\{1,2,\ldots,C\} denote the set of target positive concepts, such as disease subtypes, and let 𝒴 \mathcal{Y} denote the observed bag-label space. In the classification of multiple-subtype WSIs without pure negative samples, 𝒴 = 𝒞 \mathcal{Y}=\mathcal{C} , and in classical positive-negative MIL under the Boolean OR assumption [ 18 , 19 , 20 ] , 𝒞 = { 1 } \mathcal{C}=\{1\} and 𝒴 = { 0 , 1 } \mathcal{Y}=\{0,1\} , where the label 0 0 denotes the negative class. We further define 𝒟 cb \mathcal{D}_{\mathrm{cb}} as the class-balanced instance distribution induced by the following sampling scheme: (1) sample a class uniformly from 𝒴 \mathcal{Y} ; (2) sample a bag conditional on that class; (3) sample an instance from the selected bag. This distribution is the population analog of the class-balanced occurrence statistics used by ProtoPur, where the number of instances assigned to each prototype is normalized by the number of bags per class. Therefore, classes with a larger number of bags do not dominate the purity estimate. Singleton-support instance label Let 𝒳 \mathcal{X} be the instance space. Each x ∈ 𝒳 x\in\mathcal{X} has a latent target-concept support set 𝒮 ⁡ ( x ) ⊆ 𝒞 \mathcal{S}(x)\subseteq\mathcal{C} , where c ∈ 𝒮 ⁡ ( x ) c\in\mathcal{S}(x) means that the semantic pattern of x x appears with non-negligible probability in bags of target class c c . The singleton-support label of x x is defined as Z ⁡ ( x ) := { c , 𝒮 ⁡ ( x ) = { c } , ⊥ , | 𝒮 ⁡ ( x ) | ≠ 1 . Z(x):=\begin{cases}c,&\mathcal{S}(x)=\{c\},\\ \bot,&|\mathcal{S}(x)|\neq 1.\end{cases} The complement ⊥ \bot is an operational heterogeneous class for instances without a target subtype label, covering true negatives, shared or non-specific morphology, and artifacts. The goal is to learn h : 𝒳 → 𝒞 ∪ { ⊥ } h:\mathcal{X}\to\mathcal{C}\cup\{\bot\} with low singleton-support risk R Z ​ ( h ) = Pr X ∼ 𝒟 cb ⁡ ( h ⁡ ( X ) ≠ Z ⁡ ( X ) ) . R_{Z}(h)=\Pr_{X\sim\mathcal{D}_{\mathrm{cb}}}\big(h(X)\neq Z(X)\big). III-B Semantic locality and prototype partition A pretrained pathology foundation model ϕ \phi is used to encode each instance x x into an embedding z = ϕ ⁡ ( x ) z=\phi(x) [ 21 , 22 ] . ProtoPur clusters instances from all training bags in the embedding space using k k -means, obtaining a prototype partition 𝒱 = { V l } l = 1 L \mathcal{V}=\{V_{l}\}_{l=1}^{L} . Each V l V_{l} is a local semantic region. ProtoPur is encoder-agnostic in implementation but representation-dependent in performance; a stronger encoder should make subtype-specific singleton evidence more compact and class-pure, while separating it from shared morphology and patterns. ProtoPur exploits locality at the prototype level: nearby instances in the feature space are aggregated into prototypes, whose class associations are then estimated collectively rather than from point-wise instance scores. Weak labels are noisy for individual instances, but they become statistically informative when pooled over semantic regions. The prototypes provide a stable and scalable region family for class-balanced purity estimation and for subsequent coverage-controlled selection. III-C Purity-first selection with τ \tau -coverage Bag-normalized prototype purity For a prototype V l V_{l} and a target concept c ∈ 𝒞 c\in\mathcal{C} , let m c , l m_{c,l} be the number of instances in V l V_{l} from label- c c bags, and let N c N_{c} be the number of label- c c bags. Define m ~ c , l = m c , l / N c \widetilde{m}_{c,l}=\nicefrac{{m_{c,l}}}{{N_{c}}} . ProtoPur estimates task-specific local purity by q ^ l , c = m ~ c , l / ( ∑ c ′ ∈ 𝒞 m ~ c ′ , l ) \widehat{q}_{l,c}=\nicefrac{{\widetilde{m}_{c,l}}}{{(\sum_{c^{\prime}\in\mathcal{C}}\widetilde{m}_{c^{\prime},l})}} . Normalization of the number of bags prevents labels with more bags from dominating the purity estimates. Pseudo-labeling For subtype classification tasks, ProtoPur ranks prototypes for each c c in decreasing order of q ^ l , c \widehat{q}_{l,c} . Starting from the most class-pure prototypes, it adds prototypes to a set T c ​ ( τ ) T_{c}(\tau) until every eligible positive bag for concept c c contains at least τ \tau selected instances. If a prototype is selected by multiple targets, it is assigned to the target with the largest purity score. We define I c ​ ( τ ) = ⋃ l ∈ T c ​ ( τ ) V l I_{c}(\tau)=\bigcup_{l\in T_{c}(\tau)}V_{l} , I ⁡ ( τ ) = ⋃ c ∈ 𝒞 I c ​ ( τ ) I(\tau)=\bigcup_{c\in\mathcal{C}}I_{c}(\tau) , and use 𝒜 Y i ⊆ 𝒞 ∪ { ⊥ } \mathcal{A}_{Y_{i}}\subseteq\mathcal{C}\cup\{\bot\} to denote the set of instance labels that are compatible with the bag label Y i Y_{i} . ProtoPur assigns a pseudo-label to an instance as follows: Z ~ ​ ( x i j ) = { ⊥ , Y i = 0 ∨ x i j ∉ I ⁡ ( τ ) , c , Y i ≠ 0 ∧ x i j ∈ I c ​ ( τ ) ∧ c ∈ 𝒜 Y i , unassigned , otherwise . \tilde{Z}(x_{i}^{j})=\begin{cases}\bot,&Y_{i}=0\lor x_{i}^{j}\notin I(\tau)\,,\\ c,&Y_{i}\neq 0\land x_{i}^{j}\in I_{c}(\tau)\land c\in\mathcal{A}_{Y_{i}},\\ \text{unassigned},&\text{otherwise}.\end{cases} Selection stops when the least-covered eligible bag contains τ \tau selected instances, so labeled instance counts may vary across bags. The compatibility mask 𝒜 Y i \mathcal{A}_{Y_{i}} prevents pseudo-labels that contradict the bag label; incompatible selected instances are ignored. Thus, ProtoPur prioritizes pseudo-label reliability over exhaustive coverage. Y i = 0 Y_{i}=0 denotes a pure negative bag, which may be absent in subtype-only cohorts. Using ProtoPur inside MIL ProtoPur is a pseudo-labeling method rather than a specific MIL architecture. The pseudo-labels Z ~ \tilde{Z} produced by ProtoPur can be integrated into an MIL model. The default instantiation used in this paper is an auxiliary instance loss. In implementation, this loss is the usual cross-entropy surrogate. Instances assigned to ⊥ \bot supervise the complement class of the instance classifier, while unassigned instances are excluded from the instance-level loss. Let g g and h h denote a bag classifier and an instance classifier, respectively. The training objective is ℒ ^ CE = ℒ ^ bag CE ​ ( g , Y ) + λ ​ ℒ ^ ins CE ​ ( h , Z ~ ) , \widehat{\mathcal{L}}^{\mathrm{CE}}=\widehat{\mathcal{L}}_{\mathrm{bag}}^{\mathrm{CE}}\big(g;Y\big)+\lambda\widehat{\mathcal{L}}_{\mathrm{ins}}^{\mathrm{CE}}\big(h;\tilde{Z}\big), where ℒ ^ bag CE ​ ( g , Y ) \widehat{\mathcal{L}}_{\mathrm{bag}}^{\mathrm{CE}}(g;Y) is defined as the average of CE ⁡ ( Y i , g ⁡ ( B i ) ) \operatorname{CE}\bigl(Y_{i},g(B_{i})\bigr) over all bags, and ℒ ^ ins CE ​ ( h , Z ~ ) \widehat{\mathcal{L}}^{\mathrm{CE}}_{\mathrm{ins}}(h;\tilde{Z}) is defined as the average of CE ⁡ ( Z ~ ​ ( x i j ) , h ⁡ ( x i j ) ) \mathrm{CE}\big(\tilde{Z}(x_{i}^{j}),h(x_{i}^{j})\big) over instances with assigned pseudo-labels. V Experiments V-A Experimental Setting Datasets We evaluated the proposed ProtoPur in the main bag-level and instance-level classification experiments on three publicly available datasets: TCGA-BRCA-Invasive [ 26 ] , TCGA-LUNG [ 27 , 28 ] , and BRACS [ 29 ] . TCGA-BRCA-Invasive is constructed from the invasive carcinoma subset of TCGA-BRCA rather than the entire TCGA-BRCA cohort, and is used to assess multiple-subtype classification of invasive breast cancer WSIs. TCGA-LUNG includes lung adenocarcinoma and lung squamous cell carcinoma WSIs, forming a lung cancer subtype classification task. BRACS is a breast pathology dataset with region-level annotations. TCGA-BRCA-Invasive and TCGA-LUNG are subtype-only classification tasks, where each WSI belongs to one of the target subtypes, whereas BRACS additionally contains negative samples, resulting in a classification setting with both target lesion categories and negative cases. For TCGA-BRCA-Invasive and TCGA-LUNG, the instance-level evaluation labels are derived from public manual tumor-tissue annotations of TCGA diagnostic WSIs [ 30 ] , which were originally created to enrich invasive tumor regions for molecular prediction studies rather than to provide exhaustive pixel-level tumor segmentation. Patches overlapping annotated tumor regions are treated as foreground tumor instances and inherit the corresponding slide subtype, whereas patches outside annotated tumor regions are treated as background. For BRACS, the available region-level annotations are used in the same evaluation-only manner, while the unannotated regions are excluded from evaluation. Note that these annotations delineate tumor regions rather than subtype-specific singleton evidence, so they serve only as a proxy for Z Z . TCGA-PanGlioma [ 31 ] is additionally used for pseudo-label quality evaluation (Section V-C ). Evaluation metrics For bag-level performance, we report bag-level macro AUC. For instance-level evaluation, we report three complementary AUC metrics: AUC 𝒴 \mathrm{AUC}_{\mathcal{Y}} , AUC 𝒞 \mathrm{AUC}_{\mathcal{C}} and AUC 𝒞 | F ​ G \mathrm{AUC}_{\mathcal{C}\mid FG} . AUC 𝒴 \mathrm{AUC}_{\mathcal{Y}} is the macro-average AUC over the full instance label space 𝒴 \mathcal{Y} , calculated using the prediction probabilities of all instances for all instance classes, including both subtype classes and the negative class. AUC 𝒞 \mathrm{AUC}_{\mathcal{C}} is the macro-average AUC over the subtype classes, and it is also calculated using the subtype prediction probabilities for all instances, including negative instances. In this metric, the negative class is not included as an averaged target class, but negative instances are retained in the evaluation. AUC 𝒞 | F ​ G \mathrm{AUC}_{\mathcal{C}\mid FG} is calculated over foreground instances only, after removing negative instances, and therefore focuses on subtype-to-subtype discrimination. These metrics provide a fine-grained evaluation of instance-level classification. AUC 𝒴 \mathrm{AUC}_{\mathcal{Y}} measures overall discrimination across the full label space, AUC 𝒞 \mathrm{AUC}_{\mathcal{C}} evaluates subtype scores in the presence of negative instances, and AUC 𝒞 | F ​ G \mathrm{AUC}_{\mathcal{C}\mid FG} isolates subtype discrimination among foreground instances. Implementation Details All experiments were conducted on NVIDIA RTX 4090 GPUs. For preprocessing, each WSI was tiled into non-overlapping 512 × 512 512\times 512 patches at 40 × 40\times magnification. Patch features were extracted offline using frozen CONCH [ 21 ] and UNI [ 22 ] encoders, yielding 512-dimensional and 1024-dimensional embeddings, respectively, and all subsequent models were trained on these features. For training and evaluation, we adopted a 4 4 -fold cross-validation protocol following common MIL practice. In each fold, the data was split at the WSI level into training, validation, and test sets with a ratio of 2:1:1. The validation split was used for early stopping and model selection, and the held-out test set was used only for final evaluation. Hyperparameters were tuned on the validation splits only and then held fixed across all datasets, backbones, and encoders, so that no test data influenced any hyperparameter choice. All methods share the same folds and random seed. All models were trained using the Adam optimizer with a learning rate of 2 × 10 − 4 2\times 10^{-4} and a weight decay of 1 × 10 − 5 1\times 10^{-5} , and the bag-level batch size was set to 1. The maximum number of training epochs was set to 100 100 , and early stopping was applied with a patience of 20 epochs. For ProtoPur, we used k k -means for clustering. The number of prototypes was set to k = 2000 k=2000 and the coverage threshold to τ = 5 \tau=5 for both CONCH and UNI features. The auxiliary instance loss weight λ \lambda was set to 0.3 0.3 for all experiments. All results in the main tables use this single shared hyperparameter configuration, while sensitivity analysis is given in Section V-D . For comparison methods, WENO [ 13 ] , INS [ 11 ] , and SeLa-MIL [ 15 ] were originally designed for positive-negative binary classification at the instance level. To adapt them to the multiple-subtype setting, we used CLAM-style one-vs-rest binary instance classifiers for each subtype [ 5 ] . Since the official SeLa-MIL implementation was unavailable, we reproduced it based on the original paper and used one-vs-rest negative-class construction during training. We integrated ProtoPur with DS-MIL, CLAM, and SMMILe as a plug-and-play pseudo-labeling module, since these backbones contain instance-level branches for direct pseudo-label supervision. Overall, incorporating ProtoPur consistently improves instance-level classification across different datasets, MIL backbones, and feature encoders. The gains appear not only in AUC 𝒴 \mathrm{AUC}_{\mathcal{Y}} but also in the subtype-related metrics AUC 𝒞 \mathrm{AUC}_{\mathcal{C}} and AUC 𝒞 | F ​ G \mathrm{AUC}_{\mathcal{C}\mid FG} , suggesting that ProtoPur provides useful instance-level supervision for learning subtype-discriminative evidence rather than only separating tumor and negative regions. Across the three datasets, ProtoPur improves several representative MIL architectures, including DS-MIL, CLAM, and SMMILe. Compared with their original versions, the ProtoPur-enhanced variants generally achieve stronger instance-level AUCs while maintaining competitive bag-level performance. This trend is especially important because many MIL models can obtain high bag-level AUCs without producing reliable instance-level predictions. By introducing prototype-based pseudo-labels, ProtoPur helps the instance classifier learn more subtype-aware local representations, leading to more consistent gains in instance-level evaluation. The results also show that the benefits of ProtoPur are not limited to a specific MIL backbone or dataset type. On TCGA-BRCA-Invasive and TCGA-LUNG, where the task focuses on subtype-only classification, ProtoPur improves subtype-level instance discrimination. On BRACS, which additionally contains negative samples, ProtoPur remains effective under a more challenging setting involving both lesion categories and negative instances. These results indicate that ProtoPur can improve instance-level learning in both subtype-only and negative-included classification scenarios. ProtoPur works with both CONCH and UNI features; the consistent improvements under both encoders suggest that the proposed method is not tied to a specific type of feature representation. Instead, ProtoPur can provide effective instance-level supervision for features encoded by either vision-language or purely visual pathology foundation models. Coverage-first baselines Cover-Marginal and Cover-Total are two coverage-first pseudo-labeling baselines inspired by coverage maximization in submodular subset selection and active learning [ 32 , 33 ] . Unlike ProtoPur, they select clusters by greedily increasing the coverage of target-class bags. Let n i , l n_{i,l} denote the number of instances from bag i i assigned to cluster V l V_{l} , s i s_{i} denote the current number of selected instances in bag i i , and r i = max ⁡ ( 0 , τ − s i ) r_{i}=\max(0,\tau-s_{i}) denote the remaining coverage need under the coverage threshold τ \tau . Cover-Marginal selects the cluster-class assignment that maximizes the marginal coverage gain: R marginal ( l , c ) = ∑ i : Y i = c min ( r i , n i , l ) R_{\mathrm{marginal}}(l,c)=\sum_{i:Y_{i}=c}\min(r_{i},n_{i,l}) . Cover-Total first requires the candidate cluster to provide positive marginal coverage and then ranks feasible clusters by their total occurrence in class- c c bags: R total ( l , c ) = ∑ i : Y i = c n i , l R_{\mathrm{total}}(l,c)=\sum_{i:Y_{i}=c}n_{i,l} . Other pseudo-labeling baselines We further compare ProtoPur with several representative pseudo-labeling strategies. Text-Similarity, motivated by [ 17 ] , directly uses normalized patch-to-text similarities as patch-level pseudo-labels. It is included as a lightweight text-similarity baseline to assess whether text-side semantic scores alone can provide reliable prototype-level pseudo-labels. TextSim-Coord follows the same prototype selection procedure as ProtoPur, but replaces the class-wise prototype statistics with text-similarity statistics: it scores each prototype using the similarity between its prototype centroid and class-specific text embeddings. For the two text-based baselines, class text embeddings were generated using the official CONCH prompt template. These baselines require a paired text encoder, making them inapplicable to UNI. Attention-Score uses a trained AB-MIL model and obtains soft pseudo-labels by min-max normalizing the attention scores of instances within each bag, an approach inherited from [ 13 ] . Attention-TopK also relies on a trained AB-MIL model but assigns bag labels to instances with the top- K K attention scores for c ∈ 𝒞 c\in\mathcal{C} and negative pseudo-labels to instances with the K K smallest attention scores in each bag. In the experiments, we set K K to 20 % 20\% of the number of instances in each bag. For SeLa-MIL and INS, we use the instance pseudo-labels produced internally by the trained models. Table II reports the instance-level classification performance of different methods. ProtoPur achieves the best results on both TCGA-PanGlioma and BRACS across all three instance-level AUC metrics. On TCGA-PanGlioma, ProtoPur outperforms all baselines in AUC 𝒴 \mathrm{AUC}_{\mathcal{Y}} , AUC 𝒞 \mathrm{AUC}_{\mathcal{C}} , and AUC 𝒞 | F ​ G \mathrm{AUC}_{\mathcal{C}\mid FG} , showing that the selected prototypes provide useful supervision for both overall instance classification and subtype-level discrimination. On BRACS, several attention-based and model-derived pseudo-labeling baselines degrade substantially, whereas ProtoPur remains the best, although its margin over SeLa-MIL in AUC 𝒞 \mathrm{AUC}_{\mathcal{C}} and AUC 𝒞 | F ​ G \mathrm{AUC}_{\mathcal{C}\mid FG} is small. This suggests that relying only on attention scores, text similarity, or model-internal pseudo-labels can be sensitive to negative instances and heterogeneous lesion patterns. In contrast, ProtoPur explicitly selects prototypes with high one-vs-rest class purity before applying the coverage constraint, which helps avoid frequent but non-specific clusters and leads to more precise subtype-aware instance supervision. V-A Experimental Setting Datasets We evaluated the proposed ProtoPur in the main bag-level and instance-level classification experiments on three publicly available datasets: TCGA-BRCA-Invasive [ 26 ] , TCGA-LUNG [ 27 , 28 ] , and BRACS [ 29 ] . TCGA-BRCA-Invasive is constructed from the invasive carcinoma subset of TCGA-BRCA rather than the entire TCGA-BRCA cohort, and is used to assess multiple-subtype classification of invasive breast cancer WSIs. TCGA-LUNG includes lung adenocarcinoma and lung squamous cell carcinoma WSIs, forming a lung cancer subtype classification task. BRACS is a breast pathology dataset with region-level annotations. TCGA-BRCA-Invasive and TCGA-LUNG are subtype-only classification tasks, where each WSI belongs to one of the target subtypes, whereas BRACS additionally contains negative samples, resulting in a classification setting with both target lesion categories and negative cases. For TCGA-BRCA-Invasive and TCGA-LUNG, the instance-level evaluation labels are derived from public manual tumor-tissue annotations of TCGA diagnostic WSIs [ 30 ] , which were originally created to enrich invasive tumor regions for molecular prediction studies rather than to provide exhaustive pixel-level tumor segmentation. Patches overlapping annotated tumor regions are treated as foreground tumor instances and inherit the corresponding slide subtype, whereas patches outside annotated tumor regions are treated as background. For BRACS, the available region-level annotations are used in the same evaluation-only manner, while the unannotated regions are excluded from evaluation. Note that these annotations delineate tumor regions rather than subtype-specific singleton evidence, so they serve only as a proxy for Z Z . TCGA-PanGlioma [ 31 ] is additionally used for pseudo-label quality evaluation (Section V-C ). Evaluation metrics For bag-level performance, we report bag-level macro AUC. For instance-level evaluation, we report three complementary AUC metrics: AUC 𝒴 \mathrm{AUC}_{\mathcal{Y}} , AUC 𝒞 \mathrm{AUC}_{\mathcal{C}} and AUC 𝒞 | F ​ G \mathrm{AUC}_{\mathcal{C}\mid FG} . AUC 𝒴 \mathrm{AUC}_{\mathcal{Y}} is the macro-average AUC over the full instance label space 𝒴 \mathcal{Y} , calculated using the prediction probabilities of all instances for all instance classes, including both subtype classes and the negative class. AUC 𝒞 \mathrm{AUC}_{\mathcal{C}} is the macro-average AUC over the subtype classes, and it is also calculated using the subtype prediction probabilities for all instances, including negative instances. In this metric, the negative class is not included as an averaged target class, but negative instances are retained in the evaluation. AUC 𝒞 | F ​ G \mathrm{AUC}_{\mathcal{C}\mid FG} is calculated over foreground instances only, after removing negative instances, and therefore focuses on subtype-to-subtype discrimination. These metrics provide a fine-grained evaluation of instance-level classification. AUC 𝒴 \mathrm{AUC}_{\mathcal{Y}} measures overall discrimination across the full label space, AUC 𝒞 \mathrm{AUC}_{\mathcal{C}} evaluates subtype scores in the presence of negative instances, and AUC 𝒞 | F ​ G \mathrm{AUC}_{\mathcal{C}\mid FG} isolates subtype discrimination among foreground instances. Implementation Details All experiments were conducted on NVIDIA RTX 4090 GPUs. For preprocessing, each WSI was tiled into non-overlapping 512 × 512 512\times 512 patches at 40 × 40\times magnification. Patch features were extracted offline using frozen CONCH [ 21 ] and UNI [ 22 ] encoders, yielding 512-dimensional and 1024-dimensional embeddings, respectively, and all subsequent models were trained on these features. For training and evaluation, we adopted a 4 4 -fold cross-validation protocol following common MIL practice. In each fold, the data was split at the WSI level into training, validation, and test sets with a ratio of 2:1:1. The validation split was used for early stopping and model selection, and the held-out test set was used only for final evaluation. Hyperparameters were tuned on the validation splits only and then held fixed across all datasets, backbones, and encoders, so that no test data influenced any hyperparameter choice. All methods share the same folds and random seed. All models were trained using the Adam optimizer with a learning rate of 2 × 10 − 4 2\times 10^{-4} and a weight decay of 1 × 10 − 5 1\times 10^{-5} , and the bag-level batch size was set to 1. The maximum number of training epochs was set to 100 100 , and early stopping was applied with a patience of 20 epochs. For ProtoPur, we used k k -means for clustering. The number of prototypes was set to k = 2000 k=2000 and the coverage threshold to τ = 5 \tau=5 for both CONCH and UNI features. The auxiliary instance loss weight λ \lambda was set to 0.3 0.3 for all experiments. All results in the main tables use this single shared hyperparameter configuration, while sensitivity analysis is given in Section V-D . For comparison methods, WENO [ 13 ] , INS [ 11 ] , and SeLa-MIL [ 15 ] were originally designed for positive-negative binary classification at the instance level. To adapt them to the multiple-subtype setting, we used CLAM-style one-vs-rest binary instance classifiers for each subtype [ 5 ] . Since the official SeLa-MIL implementation was unavailable, we reproduced it based on the original paper and used one-vs-rest negative-class construction during training. We integrated ProtoPur with DS-MIL, CLAM, and SMMILe as a plug-and-play pseudo-labeling module, since these backbones contain instance-level branches for direct pseudo-label supervision.
