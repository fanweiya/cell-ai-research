3 Evaluation Design 3.1 Evaluation settings Models run in agent harnesses that manage file access, code execution, and tool interactions. In one setting, visual question answering uses native 3D artifacts accessed through the agent harness’s file and code-execution tools ( Harness + 3D ), allowing geometric and structural calculations. The same workflow is augmented with MCP viewer inspection and measurement tools ( Harness + 3D + MCP ); tool use is optional, so the setting permits either computation or visual inspection. The third setting is visual question answering from prescribed rendered 2D images using an agent harness ( Harness + 2D ). We use these compact labels in tables, figures, and configuration comparisons. In the rendered-image setting, the main comparison uses six fixed camera positions and a fixed image order; agents cannot request another view. Medical tasks pair volume renders with slices, yielding twelve images for six nominal views. All settings use the same VQA questions, response requirements, and task-specific deterministic final-answer scoring rules. The archived score exports label Harness + 3D and Harness + 3D + MCP as Source and Source+MCP , respectively. These evaluation settings specify different evidence representations and operations, not identical visual inputs. Harness + 3D–Harness + 2D differences therefore do not isolate active observation. Harness + 3D outperforms Harness + 2D for every tested model; MCP comparisons show smaller, bidirectional changes. Equal domain quotas do not reflect scientific question frequencies; subdomains and object families remain uneven. Because selection used prior model performance, scores do not estimate difficulty for randomly sampled scientific questions. Reference inspections and annotation effort do not establish a human performance baseline. Reference answers may be incorrect; accepted-answer rules affect scores. Execution differences, incomplete repeats, and uncertain earlier runs limit capability attribution. Even with native 3D objects and code execution, current models still struggle to make reliable scientific judgments. A.6 Examples from architecture, biology, and mechanical CAD (a) Architecture. Architecture: continuity across storeys. The question asks which vertical structural members extend continuously across at least two storeys. It requests their count, shortest and longest vertical extents, and whether discontinuous members exist. Coordinates use millimetres with the vertical direction as the third axis. The viewer instead uses metres with the vertical direction as its second axis. Converting between them swaps the second and third coordinates, negates the new second coordinate, and multiplies all coordinates by 1,000. The reference identifies four continuous members, with shortest and longest extents of 12,000 and 12,200 millimetres, respectively. It reports no discontinuous members. Biology: terminal residues and chain position. The question asks whether the N-terminus or C-terminus of the largest polymer chain is closer to its centre. Chain size is measured by atom count, with ties resolved by the earliest chain identifier. The centre is the alpha carbon of the middle residue, choosing the later middle residue when the chain length is even. Terminal positions use the alpha carbons of the first and last residues in file order. The task uses the first structural model and the highest-occupancy alternate positions, excluding hydrogens and solvent. The reference answer is C-terminus. Mechanical CAD: inspecting a gear assembly. The gear assembly is first shown in an oblique 3D view. The recorded inspection selects the wheel, hides the worm, and switches to a front view, exposing the wheel’s perimeter (Figure 6 c,d). The task asks for the worm wheel’s tooth count; the recorded reference is 32. A.9.2 Architecture and mechanical CAD MMArch asks architecture and civil-engineering questions grounded in figures from peer-reviewed papers ( Du et al., 2026 ) . BIM adaptive exploration instead executes code to discover model structure at runtime and answers questions in the accompanying ifc-bench v2 ( Hellin et al., 2026 ) . Thus, both architectural visual reasoning and question answering over structured building models precede ScienceVision. Our architecture tasks concern supplied objects and explicit geometric conventions within the same cross-domain scoring protocol. ABC supplies parametric curves and surfaces for geometric learning, including surface-normal estimation ( Koch et al., 2019 ) . Fusion 360 Gallery provides human design sequences and a construction environment for recovering CAD programs from target geometry ( Willis et al., 2021 ) . These resources establish geometric and construction representations, whereas ScienceVision evaluates questions about supplied CAD artifacts. VideoCAD studies long-horizon CAD interface interactions and also derives a VQA benchmark for spatial reasoning and video understanding ( Man et al., 2025 ) . BenchCAD combines visual and code question answering with image-to-code generation and instruction-guided CAD editing ( Zhang et al., 2026 ) . These benchmarks extend CAD evaluation to question answering as well as construction and editing. ScienceVision asks questions about fixed supplied artifacts and does not require reconstructing their construction histories. P3D-Bench evaluates parametric generation from text, images, and assembly specifications through executable, geometric, and structural criteria ( Yang et al., 2026b ) . CADEngBench tests parametric design and functional editing, finite-element responses, and assembly-joint grounding ( Singh et al., 2026 ) . CADWorld evaluates GUI-based FreeCAD workflows using executable checks on saved projects and auxiliary outputs ( Dong et al., 2026 ) . Their engineering outputs extend beyond ScienceVision’s final-answer checks; successful artifact creation and successful inspection answer different evaluation questions. A.9.3 Scientific structure and generated-object evaluation QM9 supplies calculated molecular geometries and quantum-chemical properties ( Ramakrishnan et al., 2014 ) . ATOM3D organizes learning tasks over three-dimensional biomolecular structures ( Townshend et al., 2021 ) . These resources connect structure to scientific prediction targets, whereas ScienceVision evaluates answers about supplied structures under stated identity and measurement conventions. SURFACEBENCH recovers symbolic surface equations from sampled three-dimensional data and combines symbolic equivalence with geometric checks ( Kabra et al., 2026 ) . Its criterion concerns discovering a representation that fits the supplied data; ScienceVision instead checks the requested properties of an existing artifact. Gen3DEval assesses generated objects for text fidelity, appearance, and surface quality using vision-language models ( Maiti et al., 2025 ) . Hi3DEval evaluates generated content at object and part levels, including material realism ( Zhang et al., 2025 ) . These quality assessments differ from checking domain-specific answers against task references, even when both evaluations use rendered views. A.9.4 Scientific workflows and evaluation boundaries DiscoveryWorld evaluates simulated discovery cycles involving hypotheses, experiments, and conclusions ( Jansen et al., 2024 ) . LabUtopia benchmarks scientific embodied agents from atomic actions through long-horizon laboratory manipulation ( Li et al., 2025 ) . The AI Scientist automates research ideas, code, experiments, and manuscript preparation in machine-learning settings ( Lu et al., 2024a ) . Co-Scientist generates and refines hypotheses for scientists, with experimental validation in selected biomedical applications ( Gottweis et al., 2026 ) . Foam-Agent automates OpenFOAM simulation workflows and exposes composable functions through MCP ( Yue et al., 2025 ) . ScienceVision’s inspection questions do not measure these broader discovery, embodied-control, or simulation-execution objectives. Execution-based grading also appears in benchmarks outside scientific visualization: SWE-bench evaluates repository issue resolution, while OSWorld checks tasks in real computer environments ( Jimenez et al., 2024 ; Xie et al., 2024 ) . ScienceVision uses task-specific final-answer checks; deterministic grading alone is therefore not a distinctive contribution relative to agent evaluation generally. MT-Bench and Chatbot Arena examine model-based judging, including position, verbosity, and self-enhancement biases ( Zheng et al., 2023 ) . Avoiding an LLM judge removes that judging stage, but does not establish the correctness of ScienceVision’s references or comparison rules. Dynabench uses human-and-model interaction to collect examples that challenge a target model ( Kiela et al., 2021 ) . This provides context for interpreting model-informed task selection, although ScienceVision does not implement the Dynabench collection protocol. Contamination studies distinguish memorization from exploitation and call for benchmark-specific exposure assessment ( Magar and Schwartz, 2022 ; Sainz et al., 2023 ) . ScienceVision’s reference provenance is not a training-data exposure audit; the available evidence does not establish that its artifacts or questions were absent from model training.
