Medical Foundation Models Medical Foundation Models (Med-FMs) have become central to modern medical image analysis, offering transferable representations that reduce the reliance on large, task-specific annotated datasets. By pre-training on large-scale medical image-text corpora, these models are able to generalize across diverse downstream tasks such as disease classification, lesion detection, and pathology recognition. Among the most influential, MedCLIP ( Wang et al., 2022 ) adapts the CLIP ( Radford and others, 2021 ) framework to chest X-rays, aligning radiology reports with image features for zero-shot classification. BioMedCLIP ( Zhang and others, 2025 ) extended this approach by training on millions of medical image-caption pairs, significantly improving cross-modal transfer. In the histopathology domain, PLIP ( Huang et al., 2023 ) and QuiltNet ( Ikezogwo et al., 2023 ) introduced pre-training strategies tailored for cell and tissue-level analysis. Zero-shot inference in VLMs refers to making predictions on new, unseen data without specific training. We denote a VLM by f θ = { f I , f T } f_{\theta}=\{f_{I},f_{T}\} , where f I f_{I} and f T f_{T} are the image and text encoders, respectively. Prompt learning addresses this by introducing auxiliary learnable parameters p p on top of the text encoder f T f_{T} , optimized in few-shot settings to steer the frozen model’s response and reduce manual engineering ( Zhou et al., 2022 ) . Backdoor Attack A backdoor attack involves embedding a visible/hidden trigger (a small random or patterned patch) within a deep learning model during its training or fine-tuning phase. When the model encounters this trigger in the input data during inference, it produces a predefined output while performing normally on clean data. In a supervised classification task, a normally trained classifier f θ : 𝒳 → 𝒴 f_{\theta}:\mathcal{X}\rightarrow\mathcal{Y} maps a clean input image 𝐱 ∈ 𝒳 \bm{\mathrm{x}}\in\mathcal{X} to a label y ∈ 𝒴 y\in\mathcal{Y} . Parameters θ \theta are learned from a training dataset 𝒟 = { 𝐱 i , y i } i = 1 N \mathcal{D}=\{\bm{\mathrm{x}}_{i},y_{i}\}_{i=1}^{N} where 𝐱 i ∈ 𝒳 \bm{\mathrm{x}}_{i}\in\mathcal{X} and y i ∈ 𝒴 y_{i}\in\mathcal{Y} . Attacker’s Objective and Capabilities The attacker aims to embed a targeted backdoor into a Med-FM during downstream adaptation, so that the adapted model behaves normally on clean inputs but predicts an attacker-chosen target class whenever a trigger is present. The backdoor must remain stealthy under standard validation, which relies only on clean data. Following prior work on medical backdoor attacks ( Feng et al., 2022 ) , we assume the attacker can poison only a small fraction of the downstream training data and can apply the trigger to inputs at inference time. Because annotated medical data are scarce and the attacker is computationally limited, full fine-tuning of the Med-FM is impractical. The attacker therefore exploits prompt learning, which changes model behavior while keeping the backbone frozen. We consider two realistic scenarios. In the first, the attacker acts as a malicious service provider: a user supplies clean labeled data and receives a task-specific prompt that has been backdoored during training. In the second, the attacker distributes backdoored prompts through public repositories (e.g., Hugging Face), where users may integrate them with their own Med-FMs. In both cases, the backdoor is introduced through the prompt, allowing the attacker to compromise deployments without modifying model weights or accessing private training pipelines. Defender’s Objective and Capabilities The defender aims to deploy a Med-FM safely for a downstream medical task, preserving high clean accuracy while preventing triggered inputs from being steered to the target class. The defense must work under the same clinical constraints as adaptation itself, namely limited labeled data and a frozen backbone. We assume the defender has access to the pre-trained Med-FM, the deployment prompt, which may be compromised, and a small clean labeled set for the task. Like the attacker, the defender cannot retrain or modify the backbone. Since the backdoor is introduced through the prompt rather than the model weights, the defender operates entirely at the prompt level. Instead of discarding the suspect prompt or retraining the model, the defender learns a new prompt that preserves clean-task utility while suppressing backdoor behavior, using the suspect prompt as a reference for the compromised region of the embedding space. 3.3 Backdoor Attack using Prompt Learning (BAPLe) BAPLe ( Hanif et al., 2024 ) , as shown in Figure 1 (a), is a backdoor attack method that exploits the multimodal nature of medical vision-language models (Med-VLMs). For computational efficiency, it injects a small set of learnable parameters (text prompts) into the input space of the model’s text encoder while keeping the backbone frozen during training on a poisoned downstream dataset. The prompt-based mechanism is particularly well suited to few-shot settings: by tailoring the input space, it enables a Med-FM to leverage pretrained multimodal knowledge for data-scarce tasks without requiring extensive retraining or large medical datasets. To further increase attack effectiveness, the method also adds imperceptible and learnable noise as a backdoor trigger to the input images, which subtly increases the model’s sensitivity to backdoor activation. By combining learnable text prompts in the text encoder with an imperceptible image trigger, this approach takes advantage of the full multimodal capabilities of Med-VLMs. Zero-shot inference in a Med-FM depends on hand-engineered text prompts, and prompt learning therefore replaces fixed templates with a small set of learnable token embeddings p p . In this setting, an attacker first learns prompts p s p_{s} and a noise trigger δ s \delta_{s} on a source model f s f_{s} . These artifacts are then applied directly, without re-optimization, to a different target model f t f_{t} during inference. The learnable noise trigger is bounded by an ℓ ∞ \ell_{\infty} budget of ϵ = 8 / 255 \epsilon=8/255 , and a fixed backdoor patch of size 24 × 24 24\times 24 is inserted at the bottom-left corner of each image. Each class is considered as a possible attack target, and final results are averaged across all target classes to ensure fairness in evaluation. Datasets We conduct experiments across six benchmark medical imaging datasets spanning both radiology and histopathology domains. These datasets span two imaging modalities (radiology and pathology) and provide a comprehensive testbed for studying both attack persistence and defense effectiveness. Clean Accuracy (CA) is the classification accuracy on unperturbed test samples and reflects the model’s utility for normal clinical use. Backdoor Accuracy (BA) is the fraction of triggered test inputs classified as the attacker-specified target class; test samples whose true label is the target class are excluded. A high BA indicates a successful attack, and a reduction in BA after a defense indicates effective mitigation. Two difference-based metrics quantify cross-model transferability. Clean Accuracy Difference (CAD) is the gap in clean accuracy on the target model between prompts learned directly on it and prompts transferred from the source model (Equation 5 ); a small CAD indicates that clean performance is preserved under transfer. Backdoor Accuracy Difference (BAD) is the corresponding gap in BA between target-learned and source-transferred attacks (Equation 6 ); a small BAD indicates that the backdoor remains effective after transfer. Compared to the clean prompt baseline, existing backdoor attacks such as BadNets, WaNet, and FIBA exhibit mixed performance, with modest gains in backdoor accuracy (BA) but generally inconsistent behavior across different datasets and models. In contrast, BAPLe consistently achieves near-perfect BA (often above 0.95 0.95 ) across MedCLIP, BioMedCLIP, PLIP, and QuiltNet, while maintaining clean accuracy (CA) at levels comparable to the clean baseline. This demonstrates that BAPLe is effective at embedding backdoors without noticeably degrading performance on unperturbed samples. These results highlight prompt learning as an effective attack surface. Whereas the baselines rely on fixed perturbations, BAPLe jointly learns the noise trigger and the prompt alongside a patch trigger, allowing the backdoor to be implanted reliably while the encoders remain frozen. Since backdoors can thus remain hidden in prompt embeddings, settings where prompts or adapters are shared across medical AI pipelines are at risk, which calls for defenses that target the prompt space rather than only model weights. To better understand how the attack operates, we examine the learned trigger and its effect on the image feature space. Figure 3 visualizes the trigger noise δ \delta learned by BAPLe for each model–dataset pair; under the ℓ ∞ \ell_{\infty} budget, the noise remains visually imperceptible across both modalities. Figure 4 shows t-SNE embeddings of image features on clean and triggered inputs. Adding the trigger shifts and reorganizes the class clusters, but the triggered features do not collapse into a single target-class cluster. This differs from conventional backdoors, where poisoned samples typically form a distinct, separable cluster in feature space. A likely explanation is that in BAPLe, target-class alignment is realized jointly through the learned prompt in the text-embedding space, so the image features alone need not collapse. This also suggests that feature-clustering defenses that inspect only image features may be less effective against prompt-based backdoors. This gain disappears when the infected-prompt anchor is removed and the prompt is trained with the cross-entropy loss alone, indicating that the improvement comes from the anchor rather than from retraining. We attribute this to the feature-divergence term acting as a regularizer: pushing the class embeddings away from the trigger-aligned configuration of the infected prompt yields embeddings that are better separated for the clean task. 6 Conclusion We presented BAPLe++, which studies prompt-based backdoors in medical foundation models from two angles. First, using the proposed CAD and BAD metrics, we showed that backdoored prompts transfer across Med-FMs, often with little loss of attack strength, but asymmetrically and in a dataset-dependent manner, so compromised prompts can propagate across deployments. Second, we proposed DePLe, a parameter-efficient defense that uses the infected prompt as a fixed anchor to learn a robust prompt without modifying the frozen backbone. Across four Med-FMs and six chest X-ray and histopathology datasets, DePLe reduces backdoor accuracy more consistently than training-free input transformations while largely preserving clean accuracy. These results call for routine auditing of adapted prompts before clinical deployment. Future work will address adaptive attacks and vision-side and multimodal prompt learning.
