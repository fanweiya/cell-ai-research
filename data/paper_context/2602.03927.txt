Appendix B Neural Network Architecture In this section, we describe the MagNet architecture used throughout the paper. We use an architecture that is schematically shown in Fig. 1 in the main text and has both self-attention and multilayer perceptron components. As we are working with a torus supercell, we use periodic features for each particle. First a feature vector f i ≡ f ⁡ ( 𝒓 i ) f_{i}\equiv f({\boldsymbol{r}}_{i}) is defined for the i i -th particle as 𝒇 i ≡ f ⁡ ( 𝒓 i ) = ( cos ⁡ ( 𝑮 1 ⋅ 𝒓 i ) cos ⁡ ( 𝑮 2 ⋅ 𝒓 i ) sin ⁡ ( 𝑮 1 ⋅ 𝒓 i ) sin ⁡ ( 𝑮 2 ⋅ 𝒓 i ) ) {\boldsymbol{f}}_{i}\equiv f({\boldsymbol{r}}_{i})=\begin{pmatrix}\cos(\G_1 \cdot\r_i)\\ \cos(\G_2 \cdot\r_i)\\ \sin(\G_1 \cdot\r_i)\\ \sin(\G_2 \cdot\r_i)\end{pmatrix} (14) where 𝑮 a {\boldsymbol{G}}_{a} ( a = 1 , 2 a=1,2 ) denote the two supercell reciprocal vectors 𝑮 a ⋅ 𝑳 b = 2 ​ π ​ δ a ​ b {\boldsymbol{G}}_{a}\cdot{\boldsymbol{L}}_{b}=2\pi\delta_{ab} with 𝑳 a {\boldsymbol{L}}_{a} ( a = 1 , 2 a=1,2 ) are the two basis vector of the torus. This feature vector represent a periodized version of the particle coordinates. Each feature vector is then mapped to an initial 𝒉 i 0 {\boldsymbol{h}}_{i}^{0} vector which lives in a higher dimensional space through a transformation, 𝒉 i 0 = W 0 ​ 𝒇 i {\boldsymbol{h}}_{i}^{0}=W^{0}{\boldsymbol{f}}_{i} (15) with W 0 ∈ ℝ d L × ℝ 2 ​ d dim W^{0}\in\mathbb{R}^{d_{L}}\times\mathbb{R}^{2d_{\rm dim}} with d L d_{L} is the dimension of the higher dimensional space where the particle coordinates are embedded which corresponds to the width of the internal layers of the neural network. d dim d_{\rm dim} is the spatial dimension ( d dim = 2 d_{\rm dim}=2 in our case). Importantly, W 0 W^{0} is the same for each particle coordinate. Having mapped the coordinates of all particles to vectors { 𝒉 i 0 } \{{\boldsymbol{h}}_{i}^{0}\} , these vectors undergo two different types of transformations, multi-head self attention followed by multilayer perceptron (MLP) which we explain next. B.1 Multilayer Perceptron (MLP) MLPs are standard feed-forward neural networks that implements the following transformation on a generic vector 𝒈 1 ∈ ℝ d L {\boldsymbol{g}}_{1}\in\mathbb{R}^{d_{L}} to yield another vector 𝒈 2 {\boldsymbol{g}}_{2} , 𝒈 2 = 𝒈 1 + F ⁡ ( W ​ 𝒈 1 + 𝒃 ) {\boldsymbol{g}}_{2}={\boldsymbol{g}}_{1}+F(W{\boldsymbol{g}}_{1}+{\boldsymbol{b}}) (16) with W W is a linear transformation W ∈ ℝ d L × ℝ d L W\in\mathbb{R}^{d_{L}}\times\mathbb{R}^{d_{L}} and 𝒃 ∈ ℝ d L {\boldsymbol{b}}\in\mathbb{R}^{d_{L}} is a bias vector. F F here represents a non-linear activation function which we choose to be the GELU function. B.2 Self-attention In the NN architecture (Fig. 1 in the main text), MLPs act individually on each particle without mixing different particle streams which cannot describe correlations between particles. In order to capture such correlations, we utilize the self-attention mechanism 47 which form the basis of transformers used in large language models. Self-attention mechanism learns how each particle is influenced by the remaining particles. Self attention acts of all set of particle streams in the l l -layer { 𝒉 i l } \{{\boldsymbol{h}}_{i}^{l}\} to generate intermediate streams { 𝒈 i l } \{{\boldsymbol{g}}_{i}^{l}\} that are then passed to the MLP ( 16 ). Schematically we have the following, ⋯ → { 𝒉 i l } → SELF − ATTN { 𝒈 i l } → PERCEPTRON { 𝒉 i l + 1 } → ⋯ \cdots\rightarrow\{{\boldsymbol{h}}_{i}^{l}\}\xrightarrow{\rm SELF-ATTN}\{{\boldsymbol{g}}_{i}^{l}\}\xrightarrow{\rm PERCEPTRON}\{{\boldsymbol{h}}_{i}^{l+1}\}\rightarrow\cdots (17) In the self-attention mechanism, three features for each element in { h i l } \{h_{i}^{l}\} are defined which are called keys , queries and values and are defined as, 𝒌 i l ​ h = W k l ​ h ​ 𝒉 i l , W k l ​ h ∈ ℝ d attn × ℝ d L {\boldsymbol{k}}_{i}^{lh}=W_{k}^{lh}{\boldsymbol{h}}_{i}^{l},\>\>W_{k}^{lh}\in\mathbb{R}^{d_{\rm attn}}\times\mathbb{R}^{d_{L}} (18) 𝒒 i l ​ h = W q l ​ h ​ 𝒉 i l , W q l ​ h ∈ ℝ d attn × ℝ d L {\boldsymbol{q}}_{i}^{lh}=W_{q}^{lh}{\boldsymbol{h}}_{i}^{l},\>\>W_{q}^{lh}\in\mathbb{R}^{d_{\rm attn}}\times\mathbb{R}^{d_{L}} (19) 𝒗 i l ​ h = W v l ​ h ​ 𝒉 i l , W v l ​ h ∈ ℝ d attnvals × ℝ d L {\boldsymbol{v}}_{i}^{lh}=W_{v}^{lh}{\boldsymbol{h}}_{i}^{l},\>\>W_{v}^{lh}\in\mathbb{R}^{d_{\rm attnvals}}\times\mathbb{R}^{d_{L}} (20) The transformations { W k l ​ h , W q l ​ h , W v l ​ h } \{W_{k}^{lh},W_{q}^{lh},W_{v}^{lh}\} are the same for each particle i i . We use multi-head attention where more than one self-attention operation is applied, indexed by h h in W k l ​ h W_{k}^{lh} , W q l ​ h W_{q}^{lh} and W v l ​ h W_{v}^{lh} which is not to be confused with the particle stream vectors 𝒉 i l {\boldsymbol{h}}_{i}^{l} . The dimensions d attn d_{\rm attn} and d attnvals d_{\rm attnvals} are different from d L d_{L} and are generally much smaller. The keys and queries vectors have the same vector space dimension d attn d_{\rm attn} to allow for comparison between two different particle streams i , j i,j through the dot product 𝒌 i l ​ h ⋅ 𝒒 j l ​ h {\boldsymbol{k}}_{i}^{lh}\cdot{\boldsymbol{q}}_{j}^{lh} . The values 𝒗 i l ​ h {\boldsymbol{v}}_{i}^{lh} is a measure of the influence on particle i i from the remaining particles j ≠ i j\neq i . The value of self-attention for each particle i i is computed as SELFATTN i ​ ( { 𝒉 j l } , W k l ​ h , W q l ​ h , W v l ​ h ) = 1 𝒩 ​ ∑ j = 1 N exp ⁡ ( 𝒌 i l ​ h ⋅ 𝒒 j l ​ h ) ​ 𝒗 j l ​ h {\rm SELFATTN}_{i}(\{{\boldsymbol{h}}_{j}^{l}\};W_{k}^{lh},W_{q}^{lh},W_{v}^{lh})=\frac{1}{\mathcal{N}}\sum_{j=1}^{N}{\rm exp}({\boldsymbol{k}}_{i}^{lh}\cdot{\boldsymbol{q}}_{j}^{lh}){\boldsymbol{v}}_{j}^{lh} (21) with a normalization factor, 𝒩 = d attnvals ​ ∑ j = 1 N exp ⁡ ( 𝒌 i l ​ h ⋅ 𝒒 j l ​ h ) \mathcal{N}=\sqrt{d_{\rm attnvals}}\sum_{j=1}^{N}{\rm exp}({\boldsymbol{k}}_{i}^{lh}\cdot{\boldsymbol{q}}_{j}^{lh}) (22) The physical meaning of ( 21 ) is transparent. The self-attention value of particle i i returns the value 𝒗 j l ​ h {\boldsymbol{v}}_{j}^{lh} of particle stream j j weighted by the exponential factor which measures the correlations between i , j i,j such that the most relevant particles j j for each particle j j are identified. The intermediate streams are given by 𝒈 i l + 1 = 𝒉 i l + W o l ​ concat h ​ [ SELFATTN i ​ ( { 𝒉 j l } , W k l ​ h , W q l ​ h , W v l ​ h ) ] {\boldsymbol{g}}_{i}^{l+1}={\boldsymbol{h}}_{i}^{l}+W_{o}^{l}\>{\rm concat}_{h}\>[{\rm SELFATTN}_{i}(\{{\boldsymbol{h}}_{j}^{l}\};W_{k}^{lh},W_{q}^{lh},W_{v}^{lh})] (23) All values of self-attention from the multi-head attention are concatenated then transformed through transformation W 0 l ∈ ℝ d L × ℝ N heads × attnvals W_{0}^{l}\in\mathbb{R}^{d_{L}}\times\mathbb{R}^{N_{\rm heads}\times{\rm attnvals}} . The intermediate streams { 𝒈 i l } \{{\boldsymbol{g}}_{i}^{l}\} are passed through MLP giving rise to, 𝒉 i l + 1 = 𝒈 i l + F ⁡ ( W l ​ 𝒈 i l + 𝒃 l + 1 ) {\boldsymbol{h}}_{i}^{l+1}={\boldsymbol{g}}_{i}^{l}+F(W^{l}{\boldsymbol{g}}_{i}^{l}+{\boldsymbol{b}}^{l+1}) (24) Here W l W^{l} and 𝒃 l {\boldsymbol{b}}^{l} are the same for all particle streams which are labeled by i i . This property is inherited from the form of the self-attention operations ( 21 ).
