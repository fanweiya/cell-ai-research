3 Method Our goal is to generate synthetic data without requiring additional pixel level annotation, to improve downstream models trained on both real and synthetic data. To do so, we use a segmentation mask ( M M ) as input to generate an image ( I I ) that follows the mask structure. Formally, let I ∈ ℐ I\in\mathcal{I} denote a medical image, M ∈ ℳ M\in\mathcal{M} its semantic mask, and T ∈ 𝒯 T\in\mathcal{T} a text prompt. In the first stage, we train a conditional diffusion model (ControlNet ( Zhang et al., 2023 ) ) to model the conditional distribution p θ 0 ​ ( I ∣ M , T ) p_{\theta_{0}}(I\mid M,T) by maximizing the conditional log likelihood: max θ 0 ⁡ 𝔼 ( I , M , T ) ∼ 𝒟 ​ [ log ⁡ p θ 0 ​ ( I ∣ M , T ) ] , \max_{\theta_{0}}\;\mathbb{E}_{(I,M,T)\sim\mathcal{D}}\big[\log p_{\theta_{0}}(I\mid M,T)\big], (1) which is implemented via the standard denoising objective ( Ho et al., 2020 ) . This stage yields an initial generator π 0 = π θ 0 \pi_{0}=\pi_{\theta_{0}} that produces samples consistent with the conditioning masks. However, this objective is under specified for properties that determine downstream utility, such as fine grain appearance (e.g., intensity and texture), structural alignment with the mask, and high level semantic or morphological correctness (see Fig. 2 ). As a result, samples from π 0 \pi_{0} may satisfy coarse conditioning while exhibiting critical fine grain errors along these dimensions. A common approach to address this limitation is to further align the initial generator using a scalar outcome reward model (ORM), which assigns a single reward to each generated sample. We instead propose PRISM , a Compositional Reward Model (CRM) framework that decomposes image quality into verifier grounded reward components, each targeting a specific attribute. For example, in PanNuke we evaluate cell intensity consistency and nuclei texture along with semantic structure (see Fig. 2 ), in CeDeM we enforce villi shoulder and crypt border alignment along with morphological consistency (see Fig A.1 ), and in ISIC we assess lesion intensity, mask agreement, and diagnostic class correctness (see Fig A.1 ) . Each component is evaluated by a dedicated verifier and captures a distinct aspect of correctness, including appearance fidelity, structural consistency, morphological validity, and semantic alignment. During RL alignment, π θ \pi_{\theta} denotes the current policy initialized from π 0 \pi_{0} . Formally, for a generated sample I ^ ∼ π θ ( ⋅ ∣ M , T ) \hat{I}\sim\pi_{\theta}(\cdot\mid M,T) , we define a set of rewards { r k ​ ( I ^ , M , T ) } k = 1 K \{r_{k}(\hat{I},M,T)\}_{k=1}^{K} , where each r k r_{k} corresponds to a specific quality criterion. Instead of aggregating these rewards additively, PRISM composes them through Hierarchical Constrained Propagation (HCP), enforcing an ordering over the verification objectives. In particular, low level attributes (e.g., intensity and texture) act as prerequisites for high level rewards (e.g., structural or semantic correctness), ensuring that failures in fundamental properties are not masked by success in easier objectives. The resulting reward is used to optimize π θ \pi_{\theta} via reinforcement learning. We adopt Group Distributional Policy Optimization (GDPO) ( Liu et al., 2026 ) , which enables stable training under multiple reward signals through group comparisons and decoupled component normalization. 3.1 Compositional Reward Model The Compositional Reward Model (CRM) combines K K bounded sub rewards { r k ( 𝐱 0 , 𝐜 ) ∈ [ 0 , 1 ] } \{r_{k}(\mathbf{x}_{0},\mathbf{c})\in[0,1]\} into a single scalar r CRM ∈ [ 0 , 1 ] r_{\mathrm{CRM}}\in[0,1] . Each component targets a distinct, verifiable failure mode of the generator, computed using frozen verifiers. For example, in cell histopathology (PanNuke), separate rewards assess whether the generated cells exhibit correct class specific intensity distributions, realistic texture patterns, and semantic consistency with the conditioning mask. Similar task specific decompositions are used for CeDeM (alignment, morphology, and ratio) and ISIC (lesion appearance, attributes, and diagnostic class), as illustrated in Fig. 2 . By explicitly separating these factors, CRM provides structured feedback that is aligned with the requirements of downstream tasks. PanNuke. PanNuke ( Gamper et al., 2020 ) is a nuclei segmentation dataset H&E patches and pixel level labels for five classes (neoplastic, inflammatory, connective, dead, non neoplastic epithelial). We use 1143 / 245 / 246 1143/245/246 samples for train/val/test. The downstream task is semantic segmentation using SegFormer-B3 ( Xie et al., 2021 ) (for details A.5.1 ). CeDeM ( Tyagi et al., 2024 ) is a duodenum biopsy histopathology dataset for celiac disease measurement. Villi and crypts are annotated by bisector polylines, with additional villus shoulder (VS) and crypt border (CB) annotations used to construct the conditioning maps. The downstream task is villus-to-crypt length ratio computation with MeasureNet ( Tyagi et al., 2024 ) . We use 1169 1169 samples for training, 146 146 for validation, and 146 146 for test (more details A.5.3 ). ISIC ( Codella et al., 2019 ) is a public dermoscopy benchmark for skin lesion analysis. We use the ISIC-2019 ( Codella et al., 2019 ) for multiclass diagnosis (e.g. melanoma, nevus, basal cellcarcinoma). We use 2339 2339 images for training, 252 252 for validation, and 1297 1297 for test. The downstream task is multiclass image classification with a ResNet-50 backbone ( He et al., 2016 ) . Representative conditioning masks and images for all three datasets are shown in A.1 . Implementation Details We ControlNet ( Zhang et al., 2023 ) initialized from Stable Diffusion 2.1 ( Rombach et al., 2022 ) and trained at 512 × 512 512{\times}512 resolution for conditional generation. We first run supervised ControlNet training with the standard diffusion noise prediction loss. We optimise with AdamW ( Loshchilov and Hutter, 2017 ) at learning rate (lr) 10 − 5 10^{-5} , batch size 4 4 per GPU, and image resolution 512 × 512 512{\times}512 , for up to 250 250 epochs. The best checkpoint π 0 \pi_{0} is selected by lowest validation FID, and GDPO finetuning is launched from the same π 0 \pi_{0} for every reward variant. To construct synthetic datasets, we sample from π 0 \pi_{0} using augmented conditioning masks. Augmentations include geometric transforms (rotation, flip, translation), structural perturbations (e.g., random removal of cells or villi), and scale variations (zoom in/out for ISIC). Further details are provided in Appendix A.3 . For RL finetuning using GDPO, we use AdamW optimizer, lr of 10 − 6 10^{-6} , group size 32, clip ratio 0.1, inner iterations 2 and DDIM sampling steps 100 (more details Tab. 4 ). For downstream model we use ISIC - ResNet50 ( He et al., 2016 ) , lr 10 − 4 10^{-4} , batch size 64 , PanNuke - Segformer ( Xie et al., 2021 ) with lr 6X 10 − 5 10^{-5} and MeasureNet ( Tyagi et al., 2024 ) with lr 10 − 4 10^{-4} , more details (see A.5 ). All experiments were conducted on 80GB A100 GPUs. RL fine tuning of generator (ControlNet) with GDPO uses 8×A100 GPUs and requires approximately 48 hours, followed by 4–8 hours for sample generation, depending on the dataset and downstream training times of 6 hours for ResNet, 10 hours for SegFormer, and 18 hours for MeasureNet. Evaluation Metrics For PanNuke, we report mean IoU and mean Dice. For CeDeM, we report mean absolute error (MAE) and mean relative error (MRE) for the villus, crypt, villi-to-crypt ratio. However, in cases of images with class level distinct attributes, improving the fine grain appearance cues such as intensity and texture, before a final task reward, is beneficial as observed on PanNuke, and ISIC. 6 Conclusion We presented PRISM , a framework for aligning mask conditional diffusion models using a Compositional Reward Model (CRM) with hierarchical constrained propagation (HCP). Instead of a single scalar reward, CRM decomposes image quality into naturally occurring verifier grounded sub rewards targeting distinct failure modes, including intensity, texture, structural consistency, and semantic correctness. HCP enforces a fine to coarse reward hierarchy, preventing higher level objectives from masking low level errors. Combined with GDPO, PRISM consistently improves over SFT, ORM, and the SUM/MaxMin aggregation baselines across three downstream task types across PanNuke, CeDeM, and ISIC. Same recipe can be used for other conditional medical image generation applications. We will release code, models and generated dataset for further study. The deployed intensity verifier uses a precomputed reference bank instead of fitting statistics online during reward evaluation. For each class region, we extract Gray-Level Co-occurrence Matrix statistics and multi-scale Gabor responses, concatenate them into 𝒯 c \mathcal{T}_{c} , and score them with a class-conditional descriptor GMM Q c Q_{c} . A.2.2 CeDeM CRM CeDeM uses the ordered reward tuple ( r anchor , r morph , r ratio ) (r_{\mathrm{anchor}},r_{\mathrm{morph}},r_{\mathrm{ratio}}) , matching Section 3.2 . The verifier first runs the frozen segmenter followed by MeasureNet on 𝐱 0 \mathbf{x}_{0} to obtain predicted villus and crypt masks, shoulder anchors, crypt borders, and the derived villus-to-crypt ratio. Rewards are then computed from these predicted geometric primitives against the conditioning mask and its annotations. Anchor consistency. This component corresponds to r anchor r_{\mathrm{anchor}} in Eq. 7 . It checks the local anatomical anchors that drive the measurement: villus shoulders (VS) and the adjacent crypt border (CB). The segmentation term d seg d_{\mathrm{seg}} measures agreement between the predicted and conditioning villus/crypt support near these anchors. The contour term d dtw d_{\mathrm{dtw}} aligns CB each VS with Dynamic Time Warping. This reward is therefore an anchor-and-local-contour check. Morphological consistency. This component corresponds to r morph r_{\mathrm{morph}} in Eq. 8 . It compares the predicted and reference villus/crypt polylines using Earth Mover’s Distance d emd d_{\mathrm{emd}} . Unlike the anchor reward, which focuses on shoulder-local structure, the morphology reward measures the global geometric agreement of the predicted anatomical curves. Ratio consistency. This component corresponds to r ratio r_{\mathrm{ratio}} in Eq. 9 . Median villus and crypt heights are extracted from the predicted dual mask to obtain ρ ^ = L ^ v / L ^ c \hat{\rho}=\hat{L}^{\mathrm{v}}/\hat{L}^{\mathrm{c}} , which is compared with the target ratio ρ ⋆ \rho^{\star} using a Gaussian tolerance. This final stage is placed after anchor and morphology checks so a sample receives full ratio credit only when the underlying anatomical geometry is also plausible. A.2.3 ISIC CRM ISIC uses the ordered reward tuple ( r int , r attr , r dx ) (r_{\mathrm{int}},r_{\mathrm{attr}},r_{\mathrm{dx}}) defined in Eq. 10 . The conditioning input contains a lesion mask and diagnostic class token y y . Skin/lesion intensity. The conditioning mask separates lesion and surrounding skin pixels. For each diagnostic class, a lesion-region GMM P les ( y ) P_{\mathrm{les}}^{(y)} is fit on real images of that class, while a background-skin GMM P skin P_{\mathrm{skin}} captures normal dermoscopic skin appearance. The two GMM rewards are averaged so that the model cannot satisfy the lesion color distribution by corrupting the surrounding skin. Attribute–mask consistency. A frozen lesion segmenter ϕ les \phi_{\mathrm{les}} predicts the lesion extent on 𝐱 0 \mathbf{x}_{0} . Dice with the conditioning mask checks whether the generated lesion has the requested location and shape, independent of the diagnostic classifier. Diagnostic margin. A frozen ResNet classifier produces logits for the diagnostic classes. We use the margin reward in Eq. 5 rather than raw probability because it is sensitive to the strongest competing class and remains bounded for GDPO normalization. A.2.4 Gating and Normalisation MIN-GATE implements the prerequisite order used by the cascade. The gate G k G_{k} in Eq. 2 is computed from the cumulative product of earlier raw component scores and lower bounded by γ = 0.1 \gamma=0.1 . Thus, failing an early verifier does not make the reward exactly zero, but it prevents later semantic or measurement rewards from dominating the average when their prerequisites are absent. For policy optimisation, GDPO receives the component tuple and performs the within-group component normalization in Eq. 11 ; the gated cascade is used as the scalar reward for logging, selection, and aggregation comparisons.
