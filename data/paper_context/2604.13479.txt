2 Method 2.1 Preliminaries: SAM-Path Decoder We build on SAM-Path [ 22 ] , which extends SAM [ 13 ] with two encoders, a frozen SAM encoder and a pathology foundation model, whose outputs align into a unified feature 𝐇 ∈ ℝ N × d \mathbf{H}\!\in\!\mathbb{R}^{N\times d} ( N N spatial tokens, d d feature dimension). The decoder keeps C C learnable class prompt tokens 𝒫 ∈ ℝ C × d \mathcal{P}\!\in\!\mathbb{R}^{C\times d} that interact with 𝐇 \mathbf{H} via cross-attention to produce per-class masks y ^ c \hat{y}_{c} and IoU predictions iou ^ c \widehat{\mathrm{iou}}_{c} , c = 1 , … , C c\!=\!1,\ldots,C . The attention weights α c , i = exp ⁡ ( s c , i ) / ∑ c ′ exp ⁡ ( s c ′ , i ) \alpha_{c,i}\!=\!\exp(s_{c,i})/\sum_{c^{\prime}}\exp(s_{c^{\prime},i}) with s c , i = ( 𝐐𝐊 ⊤ ) c , i / d s_{c,i}\!=\!(\mathbf{Q}\mathbf{K}^{\!\top})_{c,i}/\sqrt{d} , where 𝐐 ∈ ℝ C × d \mathbf{Q}\!\in\!\mathbb{R}^{C\times d} and 𝐊 ∈ ℝ N × d \mathbf{K}\!\in\!\mathbb{R}^{N\times d} derive from 𝒫 \mathcal{P} and 𝐇 \mathbf{H} , depend only on feature–prompt similarity, with no mechanism to modulate aggregation by class-level complexity, which is the limitation we address. Our formulation applies broadly to cross-attention in transformer-based segmentation models beyond SAM-Path. 2.2 Dynamic Focal Attention Focal Attention Bias framework. We introduce a class-specific scalar b c ∈ ℝ b_{c}\!\in\!\mathbb{R} , broadcast across all N N spatial positions and added to the cross-attention logit for class c c before a class-wise softmax at each spatial location: α ~ c , i = exp ⁡ ( s c , i + b c ) ∑ c ′ = 1 C exp ⁡ ( s c ′ , i + b c ′ ) , Attn ~ ​ ( 𝐐 , 𝐊 , 𝐕 ) = softmax ⁡ ( 𝐐𝐊 ⊤ d ⊕ 𝐛 ) ​ 𝐕 , \tilde{\alpha}_{c,i}=\frac{\exp(s_{c,i}+b_{c})}{\sum_{c^{\prime}=1}^{C}\exp(s_{c^{\prime},i}+b_{c^{\prime}})},\quad\widetilde{\mathrm{Attn}}(\mathbf{Q},\mathbf{K},\mathbf{V})=\mathrm{softmax}\!\left(\tfrac{\mathbf{Q}\mathbf{K}^{\!\top}}{\sqrt{d}}\!\oplus\!\mathbf{b}\right)\mathbf{V}, (1) where 𝐛 = [ b 1 , … , b C ] ⊤ ∈ ℝ C \mathbf{b}\!=\![b_{1},\ldots,b_{C}]^{\top}\!\in\!\mathbb{R}^{C} and 𝐕 ∈ ℝ N × d \mathbf{V}\!\in\!\mathbb{R}^{N\times d} are values from 𝒫 \mathcal{P} . The operator ⊕ \oplus denotes broadcast addition of 𝐛 \mathbf{b} across N N spatial positions, following structured attention biases such as ALiBi [ 18 ] , T5 [ 19 ] , and Deformable DETR [ 23 ] . Setting b c = log ⁡ ω c b_{c}\!=\!\log\omega_{c} ( ω c > 0 \omega_{c}\!>\!0 ) multiplicatively rescales the c c -th score by ω c \omega_{c} uniformly across all aggregations; parameterising b c b_{c} yields a progressive family of strategies. (S1) Class Frequency Focal Attention (CFFA). CFFA sets b c b_{c} inversely proportional to pixel frequency: b c = γ ​ log ⁡ ( 1 − f c ) , γ > 0 , b_{c}=\gamma\,\log(1-f_{c}),\qquad\gamma>0, (2) where f c ∈ ( 0 , 1 ) f_{c}\!\in\!(0,1) is the normalised training-set pixel frequency of class c c and γ \gamma controls magnitude. Unlike output-level logit adjustment [ 17 ] , this prior acts on feature aggregation directly, but still conflates rarity with difficulty ( Section 3.2 ). (S2) Hard Class Focal Attention (HCFA). HCFA replaces frequency with empirical difficulty estimated from baseline performance: b c = γ ​ log ⁡ ( 1 − p c ) , p c = Dice c base ∑ c ′ = 1 C Dice c ′ base , b_{c}=\gamma\,\log(1-p_{c}),\quad p_{c}=\frac{\mathrm{Dice}_{c}^{\mathrm{base}}}{\sum_{c^{\prime}=1}^{C}\mathrm{Dice}_{c^{\prime}}^{\mathrm{base}}}, (3) where Dice c base \mathrm{Dice}_{c}^{\mathrm{base}} is the per-class validation Dice of the pre-trained baseline and p c p_{c} its normalised difficulty proxy; HCFA targets hard classes but requires a full pre-training run. (S3) Dynamic Focal Attention (DFA)—Proposed. CFFA and HCFA fix b c b_{c} before training and cannot adapt to difficulty signals that emerge during optimisation. DFA instead treats b c b_{c} as a learnable scalar δ c ∈ ℝ \delta_{c}\!\in\!\mathbb{R} optimised end-to-end: b c = δ c , 𝜹 ∈ ℝ C , b_{c}=\delta_{c},\qquad\boldsymbol{\delta}\in\mathbb{R}^{C}, (4) ∂ α ~ c , i ∂ δ c | on-diag. = α ~ c , i ​ ( 1 − α ~ c , i ) ⏟ self-gating factor , ∂ ℒ ∂ δ c = ∑ k = 1 C ∑ i = 1 N ∂ ℒ ∂ α ~ k , i α ~ k , i ( 𝟏 [ k = c ] − α ~ c , i ) , \left.\frac{\partial\tilde{\alpha}_{c,i}}{\partial\delta_{c}}\right|_{\text{on-diag.}}=\underbrace{\tilde{\alpha}_{c,i}(1-\tilde{\alpha}_{c,i})}_{\text{self-gating factor}},\quad\frac{\partial\mathcal{L}}{\partial\delta_{c}}=\sum_{k=1}^{C}\sum_{i=1}^{N}\frac{\partial\mathcal{L}}{\partial\tilde{\alpha}_{k,i}}\,\tilde{\alpha}_{k,i}\bigl(\mathbf{1}[k\!=\!c]-\tilde{\alpha}_{c,i}\bigr), (5) driving δ c \delta_{c} positive for poorly-segmented classes and suppressing it for well-segmented ones. The on-diagonal self-gating factor α ~ c , i ​ ( − α ~ c , i ) \tilde{\alpha}_{c,i}(1\!-\!\tilde{\alpha}_{c,i}) peaks when attention weights are uncertain and vanishes at saturation, yielding an implicit curriculum effect. Warm-start initialisation. Zero-initialising 𝜹 \boldsymbol{\delta} starves rare classes of gradient ( α ~ c , i ≈ 0 ⇒ \tilde{\alpha}_{c,i}\!\approx\!0\Rightarrow self-gating ≈ 0 \approx\!0 , regardless of loss). We therefore initialise 𝜹 c \boldsymbol{\delta}_{c} from a centred log-frequency prior : δ c ( 0 ) = β ⁡ ( log ⁡ π c − 1 C ​ ∑ c ′ = 1 C log ⁡ π c ′ ) , log ⁡ π c = γ ​ log ⁡ ( 1 − f c ) , \delta_{c}^{(0)}=\beta\!\left(\log\pi_{c}-\tfrac{1}{C}\sum_{c^{\prime}=1}^{C}\log\pi_{c^{\prime}}\right),\quad\log\pi_{c}=\gamma\,\log(1-f_{c}), (6) giving minority classes a positive initial bias and majority classes a negative one at zero mean shift (in practice γ = 2 \gamma\!=\!2 , β = 0.8 \beta\!=\!0.8 ). Thereafter δ c \delta_{c} is learned end-to-end with no explicit frequency or hardness constraints. Training objective. Following SAM-Path [ 22 ] , the objective sums per-class soft Dice loss ℒ dice \mathcal{L}_{\mathrm{dice}} , focal loss [ 15 ] ℒ focal \mathcal{L}_{\mathrm{focal}} , and MSE-IoU regression ℒ mse \mathcal{L}_{\mathrm{mse}} against the realised IoU ⁡ ( y ^ c , y c ) = | y ^ c ∩ y c | / | y ^ c ∪ y c | \mathrm{IoU}(\hat{y}_{c},y_{c})\!=\!|\hat{y}_{c}\cap y_{c}|/|\hat{y}_{c}\cup y_{c}| , plus an ℓ 2 \ell_{2} regulariser on the learnable biases: ℒ = ∑ c = 1 C [ ( 1 − α ) ​ ℒ dice ​ ( y ^ c , y c ) + α ​ ℒ focal ​ ( y ^ c , y c ) + μ ​ ℒ mse ​ ( iou ^ c , IoU ⁡ ( y ^ c , y c ) ) ] + λ ​ ‖ 𝜹 ‖ 2 2 , \mathcal{L}=\sum_{c=1}^{C}\!\bigl[(1-\alpha)\mathcal{L}_{\mathrm{dice}}(\hat{y}_{c},y_{c})+\alpha\,\mathcal{L}_{\mathrm{focal}}(\hat{y}_{c},y_{c})+\mu\,\mathcal{L}_{\mathrm{mse}}\!\bigl(\widehat{\mathrm{iou}}_{c},\mathrm{IoU}(\hat{y}_{c},y_{c})\bigr)\bigr]+\lambda\|\boldsymbol{\delta}\|_{2}^{2}, (7) where α ∈ [ 0 , 1 ] \alpha\!\in\![0,1] balances Dice and focal terms, μ > 0 \mu\!>\!0 weights IoU regression, and λ = 10 − 4 \lambda\!=\!10^{-4} prevents unbounded bias growth. We use a 100 × 100\times higher learning rate η b \eta_{b} for δ c \delta_{c} for rapid adaptation. Classes such as Tumor or Stroma can be harder in some regions than others, so a class-level scalar captures only average difficulty, acting as a prior, while the token-dependent 𝐐𝐊 ⊤ \mathbf{Q}\mathbf{K}^{\!\top} term preserves spatial selectivity. Spatially adaptive or region-conditioned biases capturing instance-level and intra-class difficulty are a natural extension. Broader validation across architectures (CNN–transformer hybrids, other query-based decoders) and modalities (MRI, CT), explicit attention-map comparison, and a convergence analysis remain future work. 5 Conclusion Focal loss alone is insufficient and frequency-based reweighting unreliable: CFFA fails when rare classes are not inherently hard, and HCFA needs a costly pre-training stage. DFA resolves both by learning class-specific difficulty continuously within cross-attention, outperforming all baselines across three benchmarks with only C C extra scalar parameters. The warm-start prior prevents gradient starvation, the self-gating factor gives implicit curriculum regulation, and encoding difficulty at the representation level yields model-wide gains over post-hoc gradient corrections.
