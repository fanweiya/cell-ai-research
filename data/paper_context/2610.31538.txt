4 Method To tackle this problem, we propose LACToS, a typicality-based pixel-level OOD detection method using diffusion models, which is much more robust to inlier multimodality. In Section 4.1 , we first describe an idealized extension of an existing typicality-based metric for image-level OOD detection to pixel-level anomaly localization, and several issues that limit its direct application. Then, in Section 4.2 and Section 4.3 we introduce two key techniques, superpixels and a denoising proxy, that help overcome these issues and allow for an effective and tractable approximation to pixel-level typicality. In Section 4.4 , we additionally incorporate extracted pixel-level features which can provide more informative statistical context than color alone. Throughout, we use x ⋆ x^{\star} to denote the test image and subscripts to identify specific pixels or superpixels. Similarly, we use x x (again with appropriate subscripts) to denote the corresponding random variable under the prior or posterior, with Monte Carlo realizations indexed by superscripts. 4.1 Typicality-based Anomaly Score A natural extension of the existing typicality-based OOD detection metric in Equation 3 from images to pixels is conditional typicality. It is defined as f inp ​ ( x ⋆ , j ) := | − log ⁡ p ⁡ ( x j ⋆ | x − j ⋆ ) − ℍ ⁡ ( p ⁡ ( x j | x − j ⋆ ) ) | , j ∈ 𝒥 , f^{\mathrm{inp}}(x^{\star},j):=\big|-\log{p(x^{\star}_{j}|x_{-j}^{\star})-}\mathbb{H}(p(x_{j}|x_{-j}^{\star}))\big|,\qquad j\in\mathcal{J}, (4) where the superscript inp \mathrm{inp} stands for inpainting, x j ⋆ x^{\star}_{j} and x − j ⋆ x^{\star}_{-j} are the values of pixel j j and all remaining pixels in the test image and all other pixels, respectively, and p ⁡ ( x j | x − j ⋆ ) p(x_{j}|x_{-j}^{\star}) is the distribution of prior-consistent values for pixel j j when all other pixel values are fixed at their observed values x − j ⋆ x^{\star}_{-j} . Intuitively, we define a pixel in x ⋆ x^{\star} to be OOD if it does not belong to the typical set with respect to this conditional data distribution p ⁡ ( x j | x − j ⋆ ) p(x_{j}|x_{-j}^{\star}) , given all other pixel values. Unfortunately, this direct extension of typicality to conditional distributions in Equation 4 is not a practical score for anomaly detection for the following reasons. (P1) Due to the spatial locality of pixel intensities and the smoothness of natural images, the value of a pixel given all others is often strongly constrained by nearby pixels. With conditional distributions that are concentrated on a tiny set determined by the neighboring pixels, the typicality score is unlikely to capture OOD features that span multiple adjacent pixels. (P2) In addition, a single pixel value is a sequence of length 1, which is insufficient for the theoretical guarantees of typical sets ( Equation 2 ) to hold. Indeed, the typicality test of Nalisnick et al. (2019) has been shown to exhibit poor empirical performance on single samples ( Chauhan et al., 2022 ) . (P3) It is also computationally demanding to compute the anomaly heatmap A A by approximating Equation 4 , as f inp ​ ( x ⋆ , j ) f^{\mathrm{inp}}(x^{\star},j) has to be evaluated for every pixel j ∈ 𝒥 j\in\mathcal{J} . Using N N posterior samples for a Monte Carlo estimate p ^ ​ ( x j | x − j ⋆ ) \hat{p}(x_{j}|x^{\star}_{-j}) of p ⁡ ( x j | x − j ⋆ ) p(x_{j}|x_{-j}^{\star}) for each pixel would require a total of N × | 𝒥 | N\times|\mathcal{J}| posterior samples, which is computationally prohibitive at practical image resolution H , W H,W . (P4) Finally, raw RGB values often do not capture sufficient information about local image contents, including semantic information, which can lead to subpar performance in anomaly detection tasks. 4.2 Superpixel-level Typicality Figure 3: A fine-grained superpixel decomposition of an example image. The latter requires Assumption 4.1 , which captures the intuition that, within each superpixel, individual pixel values are independent and identically distributed. For instance, Figure 3 shows a 256 × \times 256 image partitioned into 2,600 superpixels (approximately 25 pixels per superpixel on average), which would require a total of at least 2600 posterior samples using a diffusion model. This cost could be reduced by partitioning the image into fewer, larger superpixels, but these may struggle to localize small anomalies and fail to satisfy Assumption 4.1 . We overcome this problem (P3) by estimating q k inp q_{k}^{\mathrm{inp}} for all k ∈ 𝒦 k\in\mathcal{K} simultaneously using a small number of posterior samples. Intuitively, p den p^{\mathrm{den}} serves as a shared relaxation of the superpixel-specific inpainting posteriors { p k inp } k ∈ 𝒦 \{p^{\mathrm{inp}}_{k}\}_{k\in\mathcal{K}} . In each p k inp p^{\mathrm{inp}}_{k} , the complement x − S k ⋆ x^{\star}_{-S_{k}} is fully observed while x S k ⋆ x^{\star}_{S_{k}} is left unobserved. For the denoising posterior p den p^{\mathrm{den}} , there is a tension between information on x − S k ⋆ x^{\star}_{-S_{k}} and lack of information on x S k ⋆ x^{\star}_{S_{k}} , controlled by the noise level σ \sigma . With increasing σ \sigma , we lose more information about x S k ⋆ x^{\star}_{S_{k}} , which is desirable, but we also lose information about the context x − S k ⋆ x^{\star}_{-S_{k}} . To address this issue, (P4) we follow the convention of previous works ( Mousakhan et al., 2024 ; Roth et al., 2022 ; Defard et al., 2021 ) and augment RGB values with additional features. Specifically, we extract the activations of the last three layers of a pretrained ResNet ( He et al., 2016 ) ϕ \phi , as later layers of convolutional neural networks are known to encode higher-level visual structure and have been widely used as transferable representations for downstream vision tasks ( Razavian et al., 2014 ; Zeiler and Fergus, 2014 ) . The high activation dimension, denoted as C f C_{f} , can increase histogram estimation error when few samples are available. We therefore use an autoencoder trained on each ID dataset to compress the features to dimension C f ′ ( ≪ C f ) C^{\prime}_{f}(\ll C_{f}) ; in our experiments we use C f ′ = 3 C^{\prime}_{f}=3 . We evaluate LACToS on three local anomaly detection datasets spanning medical imaging, human faces, and X-ray security screening ( Table 4 ). In each case, the diffusion model in LACToS is trained only on ID images, and all methods are evaluated on a held-out test set. Each test set includes an equal number of ID images and images containing local OOD features. CHAOS ( Kavur et al., 2019 ) provides abdominal CT scans of healthy patients. We train on 3,070 inlier slices and construct a test set containing 100 healthy test slices and 100 locally anomalous slices acquired by adding synthetic tumor to each. Following common practice in CT image analysis ( Wang et al., 2021 ; Thummerer et al., 2023 ; Su et al., 2019 ) , we apply the provided body mask at evaluation to exclude background pixels. FFHQ ( Karras et al., 2019 ) is a dataset of high-quality face images, which we treat as the inlier distribution. We train on a random subset of 5,000 images, and manually curate an OOD test set of 50 photographs of movie and television characters with prosthetics or atypical facial features (e.g., scars, metal implants), verified not to overlap with FFHQ. The ID test set contains 50 randomly selected held-out FFHQ images. DVXray ( Ma et al., 2024 ) is a dataset of X-ray luggage scans, with an ID set of weapon-free bags and an OOD set containing weapons. We train on 5,000 inlier images and restrict the OOD test set to the scissors category, where targets are small and spatially confined. For randomly sampled scissor images, we used SAM 3 ( Carion et al., 2026 ) to convert the dataset’s bounding-box annotations into segmentation masks, manually discarding images with visibly inaccurate masks for a final OOD test set of 72 images. We construct an ID test set that also contains 72 images, none of which contains a weapon. Baselines & Models. We compare LACToS against six strong baselines developed for industrial defect detection, spanning representation- and reconstruction-based methods. PatchCore ( Roth et al., 2022 ) builds a coreset-subsampled memory bank of ID patch features from a frozen ImageNet-pretrained backbone and scores test patches by nearest-neighbor distance. SimpleNet ( Liu et al., 2023 ) learns a feature adapter and a discriminator that separates adapted ID features from synthetic anomalies generated by injecting Gaussian noise in feature space. SuperSimpleNet ( Rolih et al., 2024 ) extends SimpleNet with architectural and training improvements for fast, reliable surface defect detection. EfficientAD ( Batzner et al., 2024 ) combines a lightweight student–teacher model with an autoencoder to detect local structural anomalies and violations of global logical constraints through feature discrepancies. GLASS ( Chen et al., 2024 ) trains a discriminator to separate ID features from synthetic anomalies generated using gradient ascent with truncated projection in feature space and local texture overlays in image space. DDAD ( Mousakhan et al., 2024 ) conditions a denoising diffusion model on the test image to produce an ID reconstruction and scores anomalies by feature-space discrepancy. LACToS requires an unconditional diffusion model and a posterior sampler. For all benchmarks, we use the guided-diffusion U-Net of Dhariwal and Nichol (2021) with diffusion posterior sampling (DPS) ( Chung et al., 2022 ) at inference time. Following standard practice, we pool pixel-level anomaly scores across all test images and evaluate three complementary pixel-level detection metrics. AUROC captures the relative ordering of heatmap values against the ground-truth anomaly mask, but can reward low-contrast heatmaps that flag many ID pixels as nearly as anomalous as the true OOD pixels. AP summarizes precision across recall levels, weighting each precision value by the corresponding increase in recall. AUPRO is the normalized area under the per-region overlap curve up to a false positive rate of 0.3 0.3 , where per-region overlap is the fraction of correctly detected pixels within each connected ground-truth anomalous region, averaged equally across regions. When different anomalies have different sizes, AUPRO weights all anomalies equally rather than overweighting large anomalies. We leverage a pretrained diffusion model to represent the inlier distribution, and combine it with a statistical approach that scores image regions by their typicality (or rather, atypicality) under the conditional distribution induced by their surrounding context. Empirically, LACToS shows strong performance across diverse local OOD detection tasks ranging from medical imaging to security screening. We note that since LACToS is more robust to inlier multimodality, it is also less likely to flag features from minority inlier modes as anomalous, especially when using a larger M M . We demonstrate this behavior through a toy experiment, and refer interested readers to Appendix C . It is possible that some features annotated as anomalies in the benchmarks we evaluate may be similar to features present with low frequency in the inlier (training) datasets, causing LACToS to classify them as inliers and thus generate false negative predictions according to the dataset anomaly labels. We therefore advise practitioners that, in order to maximize the accuracy of LACToS, it is important to ensure that the training set does not contain the anomalies one desires to detect. Limitations and future work. Since LACToS targets general-purpose local anomaly detection, specialized approaches can outperform LACToS for specific highly structured datasets, such as those common in industrial defect detection. A.1 Diffusion Models Diffusion models are generative models that have gained enormous popularity for their high sample quality Ho et al. (2020) ; Dhariwal and Nichol (2021) . To sample from a desired data distribution p p , these models first define a noising process (also called the forward process) as a stochastic differential equation (SDE) ( Song et al., 2020 ) of the form d ​ x = f ⁡ ( x , t ) ​ d ​ t + g ⁡ ( x , t ) ​ d ​ w , t = 0 → 1 , dx=f(x,t)dt+g(x,t)dw,\qquad t=0\rightarrow 1, (7) where w w is a standard Wiener process (Brownian motion) and f f , g g are the drift and diffusion coefficients, respectively, which are determined by a chosen noise schedule. If we denote the marginal distribution of x x at time t t as p t p_{t} , this process transforms clean data samples x ∼ p 0 := p x\sim p_{0}:=p across time until the distribution becomes pure noise at t = 1 t=1 , i.e. p 1 = 𝒩 ⁡ ( 0 , I ) p_{1}=\mathcal{N}(0,I) . Once the forward process is defined, there exists, under regularity conditions, a corresponding backward SDE with drift f ~ \tilde{f} and diffusion g ~ \tilde{g} ( Anderson, 1982 ; Song et al., 2020 ) : d ​ x = f ~ ​ ( x , t ) ​ d ​ t + g ~ ​ ( x , t ) ​ d ​ w ¯ , t = 1 → 0 , dx=\tilde{f}(x,t)dt+\tilde{g}(x,t)d\bar{w},\qquad t=1\rightarrow 0, (8) where w ¯ \bar{w} is also a Wiener process but with t t indexed backwards. This backward SDE shares the same marginal distributions p t p_{t} as the marginal distributions induced by the forward process for all t ∈ [ 0 , 1 ] t\in[0,1] . Since the drift coefficient f ~ \tilde{f} of the backward SDE has the form f ~ ​ ( x , t ) = f ⁡ ( x , t ) − g ​ ( x , t ) 2 ​ ∇ x ​ log ⁡ p t ​ ( x ) , \tilde{f}(x,t)=f(x,t)-g(x,t)^{2}\nabla_{x}\log{p_{t}(x)}, (9) a diffusion model is optimized on either a score-matching loss to predict ∇ x ​ log ​ p t ​ ( x ) \nabla_{x}\log{p_{t}(x)} Hyvärinen and Dayan (2005) ; Song et al. (2020) or on a flow-matching loss to predict f ~ ​ ( x , t ) \tilde{f}(x,t) directly Lipman et al. (2022) , and used to iteratively sample from p t p_{t} through discretization of the backward SDE. A.2 Posterior Sampling using Diffusion Models To condition generation on inference-time measurements using a pretrained diffusion model, prior works modify the reverse sampling process to approximately sample from the posterior distribution capturing simultaneous consistency with the prior encoded by the diffusion model and the likelihood induced by the measurement model Song et al. (2021) ; Kawar et al. (2022) ; Chung et al. (2022) ; Wang et al. (2022) . These methods decompose the conditional score using Bayes’ rule as ∇ x ​ log ​ p t ​ ( x | y ) = ∇ x ​ log ​ p t ​ ( x ) + ∇ x ​ log ​ p t ​ ( y | x ) , \nabla_{x}\log{p_{t}(x|y)}=\nabla_{x}\log{p_{t}(x)}+\nabla_{x}\log{p_{t}(y|x)}, (10) where ∇ x ​ log ​ p t ​ ( x ) \nabla_{x}\log{p_{t}(x)} is the unconditional score, which is provided by the pretrained diffusion model, and ∇ x ​ log ​ p t ​ ( y | x ) \nabla_{x}\log{p_{t}(y|x)} is the likelihood score, which is typically approximated to promote consistency with y y while maintaining computational tractability. These works have shown strong empirical performance on various imaging inverse problems such as inpainting, denoising, deblurring, super-resolution, and tomography; in all of these tasks the condition is given in the form of measurements y = 𝒜 ⁡ ( x ) + η y=\mathcal{A}(x)+\eta for linear or non-linear observation model 𝒜 \mathcal{A} and noise η \eta . E.3 LACToS hyperparameters For sample reconstruction using DPS ( Chung et al., 2022 ) , we utilize the identity forward model and zero-mean Gaussian noise with variance σ noise \sigma_{\mathrm{noise}} . DPS also has a scale parameter that controls the posterior guidance strength. Once M M reconstructions are computed and the corresponding features are acquired, we rescale RGB values from [ 0,255 ] [0,255] and autoencoder outputs from [ 0 , 1 ] [0,1] to a common [ 0,255 ] [0,255] range. Then, we partition the reconstructions and feature maps into superpixels containing an average of S avg S_{\mathrm{avg}} pixels each, using marker-controlled watershed segmentation ( Meyer and Beucher, 1990 ) . For each superpixel, we quantize the rescaled values into B RGB B_{\mathrm{RGB}} and B feat B_{\mathrm{feat}} bins per dimension, for RGB values and autoencoder outputs respectively. While it is ideal to construct C + C f ′ C+C^{\prime}_{f} -dimensional histograms, the number of histogram bins grows exponentially with the dimension. Therefore, we construct two empirical histograms per superpixel, one over RGB values and one over feature values. We smooth each histogram with a Gaussian kernel of σ hist \sigma_{\mathrm{hist}} to mitigate empty bins under limited samples, and use the histograms to compute the RGB and feature typicality scores for each superpixel. The two scores are summed with a weight parameter λ \lambda multiplied to the feature typicality to balance the trade-off between the two scores. Finally, we smooth the anomaly map that contains the same value over all pixels in each superpixel to acquire the pixel-level anomaly map. All parameters are selected by performing a grid search over a small subset containing 20 test images, and the configuration with the highest AUROC is used to evaluate over the full test set.
