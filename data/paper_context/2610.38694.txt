3 Methods Pack3D is a geometry-aware local–global attention operator for packed high-token 3D fields. A flattened volume may be stored in raster, Morton, or block-contiguous order, but those layouts encode memory order, not physical coordinates. Pack3D therefore enforces three contracts: local attention is exact, because microscopy carries high-frequency morphology that block summaries would erase; only nonlocal context is compressed, into contiguous block summaries; and query–key compatibility is parameterized by true 3D coordinates rather than by packed sequence index. The rest of this section makes each contract precise and shows that the executed operator realizes it. 3.1 Packed token fields and coordinate geometry This subsection fixes the distinction the whole method rests on: a token has both a memory position and a physical coordinate, and Pack3D indexes attention by the latter. The main Allen rows in § 4 all run the two-level block-Morton layout described below; Proposition 1 is what licenses treating that layout as a free systems choice, and Appendix C.3 certifies the specific repackings we test. The implementation separates physical coordinates from memory packing: local neighborhoods are computed from token-grid coordinates, while compressed summaries are built over the configured packed blocks. The reported Allen rows use the raster_block layout; the implementation also supports a two-level native_block_morton layout used for layout and systems diagnostics. Proposition 1 is what makes the layout a free choice for coordinate-indexed operators: any coordinate-preserving repacking yields the same operator up to permutation. Appendix C.2 verifies this at task level on a controlled synthetic field, where sequence-indexed encodings collapse under repacking while axial grid-coordinate RoPE remains exact. The technical contribution is the co-design of operator, layout, and kernels around these invariants: coordinate-defined neighborhoods, contiguous summaries, and a backward pass that follows the same streamed access pattern as the forward pass. The main path is summary construction, exact local attention, and query-to-summary attention. An optional selected-refinement branch routes over candidate-block tiles and can share one route decision across a native block, but it is a reach extension (Appendix D.1 ), not part of the main claim. We report backend status explicitly, so executed Triton paths, fallbacks, and branches skipped by design are never conflated. 3.5 Complexity and systems contract The cost of the operator is governed by six quantities: the local neighborhood size w = | 𝒩 ⁡ ( i ) | w=|\mathcal{N}(i)| , the block volume v = | B j | v=|B_{j}| , the number of blocks M = N / v M=N/v , the query and KV head counts H q H_{q} and H k ​ v H_{kv} , and the per-head dimension d h d_{h} . Ignoring linear projections and normalization, dense attention costs T dense = Θ ⁡ ( H q ​ N 2 ​ d h ) T_{\mathrm{dense}}=\Theta(H_{q}N^{2}d_{h}) , whereas the local–global operator costs T LG = Θ ⁡ ( H q ​ N ​ w ​ d h ) ⏟ local + Θ ⁡ ( H q ​ N ​ M ​ d h ) ⏟ query–summary + Θ ⁡ ( H k ​ v ​ M ​ v ​ d h ) ⏟ summary build . T_{\mathrm{LG}}=\underbrace{\Theta(H_{q}Nwd_{h})}_{\text{local}}+\underbrace{\Theta(H_{q}NMd_{h})}_{\text{query--summary}}+\underbrace{\Theta(H_{kv}Mvd_{h})}_{\text{summary build}}. The nonlocal comparison set shrinks from N N raw tokens per query to M = N / v M=N/v summaries, while nearby interactions stay exact. Pack3D is therefore neither linear attention nor approximate local attention: it is exact local token–token attention plus block-compressed nonlocal token–summary attention. RoPE changes the coordinate system of the logits, not the attention graph. Arithmetic sparsity buys nothing unless the implementation avoids dense intermediates. On the main path, Pack3D materializes only token activations and M M summaries; local neighborhood tiles and global summary tiles are streamed through online-softmax reductions. This avoids the two intermediates that usually erase a sparse graph’s benefit — gathered local-neighbor feature tensors and dense token-to-summary score matrices — and yields a trainable forward/backward block whose executed operator matches the local–global graph the method claims. 4 Results The experiments test an attention-method claim, not a segmentation-leaderboard claim: packed high-token 3D attention should encode physical coordinates, not memory order . The Allen-15 comparison shows Pack3D is competitive with a parameter-matched 3D U-Net on both best and final macro Dice; we do not claim segmentation state of the art or universal practical superiority over U-Net, and runtime and memory remain separate systems questions on which Window attention is in fact cheaper. Lower-priority boundary evidence is deferred to the appendix: summary-center RoPE is competitive in short gates (Appendix B.7 ), collar controls show external collar content is not the clean driver of the gain (Appendix C.6 ), and external transfer is mixed (Appendix C.7 ). Taken together, the main-paper evidence supports a specific, bounded conclusion: at matched capacity, physical-coordinate geometry improves packed high-token local–global attention; the trained model’s compressed pathway is functional rather than vestigial; and the resulting sparse graph is trainable on GPU hardware. The contribution is not a state-of-the-art segmentation model. For packed geometric fields, query–key compatibility should be indexed by physical coordinates rather than sequence positions. Pack3D instantiates this principle with exact local attention, compressed global summaries, and coordinate-aware query-relative geometry. Synthetic repacking exposes the failure mode: learned or sequence-index positional mechanisms can fit one layout and fail under another, while coordinate-indexed attention remains invariant. The operator lesson is simple: memory layout is a systems decision, not an attention coordinate system. Compressed global attention over packed 3D fields should be built in the coordinates of the sample, not the sequence used to store it. C.2 Task-level synthetic repacking benchmark The invariance diagnostics above are operator-level: they show the logits transform correctly. This subsection measures the consequence at the level of a task . We construct a controlled synthetic 3D labeling problem with a known geometric rule, train each positional mechanism on raster-packed tokens, and then evaluate the same trained model on the same physical task after changing only the memory order of the tokens. The physical coordinates and the target rule are held fixed; the sole intervention is the packing. This is the task-level form of Proposition 6 : if a mechanism has learned the memory layout rather than the geometry, repacking should destroy its predictions. It does, and cleanly (Table 9 ). Learned positional embeddings and packed-sequence RoPE both solve the raster layout perfectly — 1.000 Dice — and both collapse under repacking, to 0.449 (Morton), 0.418 (block-contiguous), and 0.378 (random). Axial grid-coordinate RoPE stays at 1.000 Dice under every repacking. A no-positional baseline is flat at 0.554 across all packings but never solves the task, confirming the task genuinely requires position: the sequence-indexed mechanisms do not merely lose their advantage under repacking, they fall below position-blindness (0.378–0.449 vs. 0.554), because they have learned to read a signal that repacking has made actively misleading. Two features of the table are worth reading deliberately. First, the learned-PE and packed-sequence-RoPE rows are identical at every packing. This is expected, not a coincidence: both mechanisms key on sequence position, so a given repacking scrambles the same information for each, and both land on the same wrong label overlap. The shared failure is the point — it is the property of being sequence-indexed, not any detail of the encoder, that repacking breaks. Second, the degraded values are exact rationals on the synthetic grid (for instance 0.449 = 22 / 49 0.449=22/49 ), reflecting the controlled finite-grid construction rather than measurement noise.
