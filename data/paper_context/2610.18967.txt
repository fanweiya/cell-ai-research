The particle streams { 𝒉 i 0 } \{\boldsymbol{h}^{0}_{i}\} are then propagated through L L identical layers, each of which first lets them exchange information through multi-head self-attention and then acts on each stream individually with a multilayer perceptron. The output streams { 𝒉 i L } \{\boldsymbol{h}^{L}_{i}\} are finally projected to produce the amplitudes F j n F^{n}_{j} and the winding maps η j ( α , n ) \eta^{(\alpha,n)}_{j} .
