Pathology foundation models and MIL. WSI analysis spans cancer detection and molecular prediction, with reliable evaluation depending on accurate reference labels [ 5 , 10 , 22 , 26 ] . Large-scale self-supervision, exemplified by UNI and Virchow, and contrastive learning produce reusable patch representations [ 8 , 39 , 42 , 41 , 53 ] . Representation learning also encompasses cell-level morphology [ 9 ] , global slide context [ 7 , 43 , 44 ] and multimodal learning from reports or molecular measurements [ 11 , 36 , 47 ] . To obtain slide predictions from patch features, ABMIL uses attention, CLAM uses clustering-constrained attention, and TransMIL models correlations among instances [ 18 , 32 , 38 ] . Related variants incorporate dual streams, agent tokens, graph interactions and distillation [ 24 , 27 , 13 , 25 , 48 ] . Conventional task-supervised MIL fits aggregation and classification parameters to each downstream task. MI-Hyper instead generates these parameters from task descriptions. 3 Methods of MI-Hyper Figure 2 : Mixed-task learning and zero-shot deployment of MI-Hyper. (a) The task registry covers 52 datasets, 308 tasks and 112 semantic groups. The global training partition contains 20,420 patients and 111,151 task–case pairs. Each fold optimizes on eligible source tasks and holds out target task IDs; cases may recur across source and target tasks. (b) Joint source-label learning is followed by fixed-basis refinement with cross-entropy and auxiliary losses (Eq. ( 8 )). (c) Task and class descriptions generate the aggregation query and classifier weights, which are reused across cases without target-task parameter updates. At deployment, each predictor reuses its generated parameters across cases and aggregates each case’s complete patch sequence. 3.1 Problem Formulation We represent a case as a bag of patch features extracted by a frozen encoder, X = { x i } i = 1 N X=\{x_{i}\}_{i=1}^{N} , where x i ∈ ℝ d x_{i}\in\mathbb{R}^{d} . A bag may contain patches from one or more slides of the same case, and its length N N varies with tissue coverage. A prediction task τ \tau is defined by an ordered vocabulary of C τ C_{\tau} classes and a text condition c τ c_{\tau} comprising class descriptions and additional task context. Given c τ c_{\tau} , the hypernetwork generates task-specific parameters and assembles them with shared components to form an MIL predictor: θ τ \displaystyle\theta_{\tau} = H ϕ ​ ( c τ ) , 𝒲 τ = 𝒜 ν ​ ( W 0 , θ τ ) , \displaystyle=H_{\phi}(c_{\tau}),\qquad\mathcal{W}_{\tau}=\mathcal{A}_{\nu}(W_{0},\theta_{\tau}), p τ ​ ( y ∣ X ) \displaystyle p_{\tau}(y\mid X) = f ν ​ ( X , 𝒲 τ ) . \displaystyle=f_{\nu}(X;\mathcal{W}_{\tau}). (1) Here, ϕ \phi denotes the generator parameters, W 0 W_{0} contains components shared across tasks, and ν \nu specifies the predictor parameterization and assembly rule. We instantiate this formulation with a gated MIL predictor. Prior hypernetwork-based transfer for WSI prognosis uses WSI-conditioned mixing and sparse aggregation of cancer-specific task vectors [ 28 ] . MI-Hyper instead conditions its generator on task and class descriptions, allowing the generated parameters to be reused across cases of the same task. 3.2 Conditional Weight Generation Our gated MIL implementation uses frozen CONCH v1.5 patch features and CONCH-Z text embeddings, both of width 768 [ 37 ] . Class names specify the required distinctions, and background descriptions place the prediction endpoint in context. A learnable adapter then maps normalized text embeddings to 256-dimensional representations. The symmetric class summary makes the query invariant to class order, while classifier rows follow the order of their descriptions. The shared decoder therefore accommodates tasks with different class counts. The dual-text generator extends the class-name branch with a joint class-name–morphology branch. This branch has a separate trainable text adapter for morphology descriptions and a fusion adapter that combines each class’s name and morphology representations. An availability mask excludes missing or unverified morphology descriptions before class summarization and nonlinear interaction. A text-conditioned gate then linearly interpolates the queries, classifier rows and biases of the two branches, component by component. The gate receives task and class text representations, pairwise similarity statistics within and between the name and morphology embeddings, and morphology availability. It does not receive patch features from the query case. Neither role includes the target task IDs for that fold. For a source task τ \tau , text condition c τ c_{\tau} and case–label pair ( X , y ) (X,y) , the prediction objective is ℒ src ​ ( W 0 , ϕ ) = 𝔼 ( τ , c τ , X , y ) ∼ 𝒟 src ​ [ − log ⁡ p τ ​ ( y ∣ X ) ] . \mathcal{L}_{\mathrm{src}}(W_{0},\phi)=\mathbb{E}_{(\tau,c_{\tau},X,y)\sim\mathcal{D}_{\mathrm{src}}}\left[-\log p_{\tau}(y\mid X)\right]. (7) Training cycles through source tasks, balances classes within each task and samples at most 2048 stored patches per case. Both pretrained encoders remain frozen. Source cross-entropy jointly trains a randomly initialized generator and shared MIL basis; the pretrained encoders remain frozen. This stage uses canonical task contexts and class-specific morphology descriptions. SOURCE-DEV selects checkpoints by task-average AUC under the canonical condition, without parameter updates. The selected generator initializes the class-name branch, and a copy of its text adapter initializes the morphology branch. Refinement fixes the projection and gated attention basis W 0 W_{0} . During fixed-basis refinement, each source case is evaluated using a canonical text condition and an augmented condition. Their mean cross-entropy defines ℒ CE \mathcal{L}_{\mathrm{CE}} , the Jensen–Shannon divergence between their prediction distributions defines ℒ JS \mathcal{L}_{\mathrm{JS}} , and the squared difference between their predicted gate scores defines ℒ gate \mathcal{L}_{\mathrm{gate}} . This proxy uses between-class and within-class dispersion of source-case mean patch features and is applied only when sample support is valid. This source-derived proxy regularizes the gate; inference still computes the gate from text alone. MI-Hyper generates and caches the aggregation query and classifier parameters once per target text condition, then reuses them across cases. Target labels are not used to generate or update these parameters at deployment. Source-data use is documented separately for the evaluation setting. The cached parameter count depends on the class vocabulary rather than bag length. Complete bags are processed in chunks with one global attention normalization (Supplementary Section S2 ). Caching avoids regenerating parameters across cases; processing each bag still scales with its patch count. 4 Experiments Training details. We train five MI-Hyper models under the 112-group partition, using the SOURCE-FIT, SOURCE-DEV and target roles defined in Methods. We optimize parameters on SOURCE-FIT training cases and select checkpoints by task-average AUC on SOURCE-DEV validation cases. Both stages run for 15 epochs with the optimizer and patch-sampling settings in Methods. Evaluation protocols. We evaluate text-conditioned MIL model construction on 308 dataset–endpoint tasks from 52 pathology datasets. The common query set contains 160,989 task–bag records and 896 task-specific classes. Because a case may support several endpoints, these records do not represent mutually independent WSIs or patients. Bags contain 10–145,183 stored patches, with a median of 1,866, and all tasks contribute to the overall statistics. Supplementary Fig. S1 summarizes endpoint, anatomical and dataset coverage. Because mutation and staging tasks account for a large share of the collection, we report group-level results alongside the overall averages to distinguish coverage from performance within each group. For each task, we evaluate its original target-fold checkpoint against MI-Zero on the same query records, using all stored patches and keeping the generator and MIL basis fixed. Seven predefined pairs of text descriptions are used for each task, with a predictor generated and evaluated separately for each condition. Although target task IDs are held out, cases can recur in other source tasks. Matching patient identifiers or feature files across tasks identifies 100,573 query records in the eligible SOURCE-FIT pool and 4,873 in SOURCE-DEV; 55,543 have no recorded match. Pool membership does not establish that every case was sampled during optimization, and an unmatched record does not rule out unrecorded exposure. The evaluation therefore measures transfer to held-out task IDs across the complete query set, rather than generalization to an entirely unseen patient population. The main text compares macro one-vs-rest AUC and balanced accuracy (BAcc); the complete task-level results additionally report macro-F1 (Supplementary Table ). All metrics are percentages. We first evaluate each condition, average condition metrics within each task, and then weight the 308 tasks equally. MI-Zero uses 50 prompts at each of K = 1 , 5 , 10 , 50 , 100 K=1,5,10,50,100 , with Mean- K K averaging all 250 condition metrics on the same query records as MI-Hyper. MI-Hyper uses all seven predefined text conditions, without choosing conditions or task-specific models from target labels. Therefore, ranking performance is more sensitive to classifier source than to query source in these tasks. 5 Conclusion Through mixed-task source training, MI-Hyper learns to generate the aggregation and classification weights of MIL predictors from pathology task descriptions. Across 308 tasks from 52 pathology datasets, its mean AUC and balanced accuracy exceed those of MI-Zero, with substantial concurrent gains on some endpoints. These findings provide experimental support for constructing WSI predictors from task descriptions. Generating one predictor per text condition and reusing it across cases offers a promising route to weight-space transfer for long visual sequences. Future work should broaden source-task coverage and investigate data augmentation. More stable weight generation will also be important for reliable prediction.
