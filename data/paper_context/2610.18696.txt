Below, we present CryoTracer , a method for detecting filament instances in high-resolution, noisy micrographs. First, we describe our proposed architecture, which modifies RF-DETR to enable a polyline-based representation of detected structures. Next, we explain a two-stage training paradigm that addresses the problem of limited annotated real data. The key components of our method are illustrated in Figure 1 . Architecture overview. Our detection model consists of an encoder ℰ θ \mathcal{E}_{\theta} and a decoder 𝒟 ϕ \mathcal{D}_{\phi} , parameterized by θ \theta and ϕ \phi , respectively. The decoder contains several learnable projection modules ( ψ , Φ , Γ ) (\psi,\Phi,\Gamma) . Although these modules have separate parameter subsets, we denote all of them by ϕ \phi for simplicity, emphasizing that they jointly constitute the decoder 𝒟 ϕ \mathcal{D}_{\phi} . Feature extraction. Given an input micrograph 𝐗 ∈ ℝ 1 × W × H \mathbf{X}\in\mathbb{R}^{1\times W\times H} , the encoder ℰ θ \mathcal{E}_{\theta} extracts a set of feature maps { 𝐅 l } l = 1 L \{\mathbf{F}_{l}\}_{l=1}^{L} from L L selected intermediate layers. Each spatial location of each feature map 𝐅 l \mathbf{F}_{l} defines one candidate polyline proposal. Initial proposal construction. For a spatial location ( x , y ) (x,y) in feature map 𝐅 l \mathbf{F}_{l} , we obtain a latent proposal representation 𝐳 i = ψ ϕ ​ ( 𝐅 l , x , y ) , \mathbf{z}_{i}=\psi_{\phi}(\mathbf{F}_{l,x,y}), (1) where, for simplicity, we use a single index i i to enumerate proposals across all feature maps. Each proposal is additionally associated with a center 𝐜 i \mathbf{c}_{i} , corresponding to the normalized spatial position ( x , y ) (x,y) , and a scale 𝐫 i \mathbf{r}_{i} determined by the feature-map level l l . Coarser feature maps correspond to larger spatial scales. From the latent representation 𝐳 i \mathbf{z}_{i} , we predict a confidence score γ i = Φ ϕ ​ ( 𝐳 i ) \gamma_{i}=\Phi_{\phi}(\mathbf{z}_{i}) . We retain the Q = 50 Q=50 proposals with the highest confidence scores. This exceeds the observed filament counts in both datasets (means: 20.3 and 5.9), while limiting decoder cost. Given the image sizes and filament widths, substantially denser scenes would also increase overlap and tracing ambiguity. For each retained proposal, an MLP Γ ϕ \Gamma_{\phi} predicts offsets for K K ordered polyline points: 𝐃 i = Γ ϕ ​ ( 𝐳 i ) , 𝐃 i ∈ ℝ K × 2 . \mathbf{D}_{i}=\Gamma_{\phi}(\mathbf{z}_{i}),\qquad\mathbf{D}_{i}\in\mathbb{R}^{K\times 2}. (2) The initial polyline is then constructed as 𝐏 i = ( 𝐜 i + tanh ⁡ ( 𝐃 i , k ) ⊙ 𝐫 i ) k = 1 K . \mathbf{P}_{i}=\left(\mathbf{c}_{i}+\tanh(\mathbf{D}_{i,k})\odot\mathbf{r}_{i}\right)_{k=1}^{K}. (3) Each row 𝐃 i , k \mathbf{D}_{i,k} specifies the offset of the k k -th polyline point relative to the proposal center. The tanh \tanh function bounds the predicted offsets, while 𝐫 i \mathbf{r}_{i} scales them according to the spatial scale associated with the corresponding feature-map level. The resulting K K ordered points form the initial polyline prediction 𝐏 i \mathbf{P}_{i} . Iterative polyline refinement. Each initial polyline is predicted independently from a single feature-map location 𝐅 l , x , y \mathbf{F}_{l,x,y} . Consequently, the initial predictions have two limitations. First, multiple proposals may correspond to the same filament, while other filaments may receive no proposal. Second, predicting the entire polyline from a single feature representation may result in inaccurate localization or shape estimates. Following RF-DETR, we address both limitations through an iterative refinement procedure depicted in Figure 1 b) and c). For each decoder query slot i i , we initialize the query content 𝐪 i ( 0 ) \mathbf{q}_{i}^{(0)} from a learned query embedding shared across images. The selected encoder proposal 𝐏 i \mathbf{P}_{i} supplies the initial reference geometry, 𝐏 i ( 0 ) = 𝐏 i \mathbf{P}_{i}^{(0)}=\mathbf{P}_{i} . At decoder layer t t , the queries first interact through self-attention, 𝐪 ~ i ( t ) = SelfAttn ϕ ⁡ ( 𝐪 i ( t − 1 ) , { 𝐪 j ( t − 1 ) } j = 1 Q ) , \tilde{\mathbf{q}}_{i}^{(t)}=\operatorname{SelfAttn}_{\phi}\left(\mathbf{q}_{i}^{(t-1)},\{\mathbf{q}_{j}^{(t-1)}\}_{j=1}^{Q}\right), (4) allowing information to be exchanged between proposals. This interaction helps the decoder reason jointly about the Q Q candidate objects rather than refining each proposal independently. Next, cross-attention aggregates information from all encoder feature levels { 𝐅 l } l = 1 L \{\mathbf{F}_{l}\}_{l=1}^{L} into query 𝐪 ~ i ( t ) \tilde{\mathbf{q}}_{i}^{(t)} . The current polyline 𝐏 i ( t − 1 ) \mathbf{P}_{i}^{(t-1)} provides the reference locations for sampling features around each of its points: 𝐪 i ( t ) = CrossAttn ϕ ⁡ ( 𝐪 ~ i ( t ) , { 𝐅 l } l = 1 L , 𝐏 i ( t − 1 ) ) . \mathbf{q}_{i}^{(t)}=\operatorname{CrossAttn}_{\phi}\left(\tilde{\mathbf{q}}_{i}^{(t)},\{\mathbf{F}_{l}\}_{l=1}^{L};\mathbf{P}_{i}^{(t-1)}\right). (5) Consequently, the query is updated using features sampled around its current polyline across all feature levels. Finally, the updated query predicts a correction to the current polyline, 𝐏 i ( t ) = Refine ϕ ⁡ ( 𝐏 i ( t − 1 ) , 𝐪 i ( t ) ) . \mathbf{P}_{i}^{(t)}=\operatorname{Refine}_{\phi}\left(\mathbf{P}_{i}^{(t-1)},\mathbf{q}_{i}^{(t)}\right). (6) The refined polyline 𝐏 i ( t ) \mathbf{P}_{i}^{(t)} and query 𝐪 i ( t ) \mathbf{q}_{i}^{(t)} are passed to the next decoder layer, progressively improving the predictions. After the final layer, the resulting polylines { 𝐏 ^ i } i = 1 Q \{\hat{\mathbf{P}}_{i}\}_{i=1}^{Q} form the decoder outputs. Training objective. Since we are representing objects with polylines, a simple regression from off-the-shelf DETR methods is not applicable. Instead, to compare the predicted polyline 𝐏 ^ i \hat{\mathbf{P}}_{i} with a ground truth polyline 𝐘 j \mathbf{Y}_{j} , we use the Fréchet Distance d F ​ ( 𝐏 ^ i , 𝐘 j ) d_{F}(\hat{\mathbf{P}}_{i},\mathbf{Y}_{j}) , which measures the spatial distance between two polylines rather than exact point-to-point alignment. To make the distance invariant to point direction (forward vs backward), we define it as d ¯ F ​ ( 𝐏 ^ i , 𝐘 j ) = min ⁡ { d F ​ ( 𝐏 ^ i , 𝐘 j ) , d F ​ ( rev ​ ( 𝐏 ^ i ) , 𝐘 j ) } , \bar{d}_{F}(\hat{\mathbf{P}}_{i},\mathbf{Y}_{j})=\min\{d_{F}(\hat{\mathbf{P}}_{i},\mathbf{Y}_{j}),d_{F}(\text{rev}(\hat{\mathbf{P}}_{i}),\mathbf{Y}_{j})\}, (7) where rev reverses the order of points. To find a proper match between the sets of predictions { 𝐏 ^ i } i = 1 Q \{\hat{\mathbf{P}}_{i}\}_{i=1}^{Q} and ground truths { 𝐘 j } j = 1 N \{\mathbf{Y}_{j}\}_{j=1}^{N} , we use Hungarian matching to find a minimum-cost one-to-one assignment that balances geometric distance d ¯ F \bar{d}_{F} and prediction confidence. Predictions not selected by the assignment are optimized as no-object (polyline confidence γ \gamma is minimized for them via the cross entropy loss term ℒ C ​ E \mathcal{L}_{CE} ). For matched polylines, we optimize the following criterion ℒ F = 1 max ⁡ ( N , 1 ) ​ ∑ j = 1 N d ¯ F ​ ( 𝐏 ^ π ⁡ ( j ) , 𝐘 j ) , \mathcal{L}_{F}=\frac{1}{\max(N,1)}\sum_{j=1}^{N}\bar{d}_{F}\left(\hat{\mathbf{P}}_{\pi(j)},\mathbf{Y}_{j}\right), (8) where π ⁡ ( j ) \pi(j) is the index of the prediction matched to the j j -th ground truth polyline. The cross-entropy loss ℒ C ​ E \mathcal{L}_{CE} also encourages high confidence for matched predictions. Combining classification and geometry gives ℒ = ℒ C ​ E + λ F ​ ℒ F , \mathcal{L}=\mathcal{L}_{CE}+\lambda_{F}\mathcal{L}_{F}, (9) with geometric loss weight λ F = 10 \lambda_{F}=10 . We apply Equation 9 independently to the final decoder predictions and the Q Q selected initial encoder proposals, obtaining ℒ dec \mathcal{L}_{\mathrm{dec}} and ℒ enc \mathcal{L}_{\mathrm{enc}} , respectively. Each prediction set has its own Hungarian assignment. Encoder supervision directly trains the proposal heads because the initial coordinates are detached before decoder refinement. We therefore compute ℒ enc \mathcal{L}_{\mathrm{enc}} from an undetached copy of the selected proposals. The decoder and encoder losses are combined as ℒ total = λ dec ​ ℒ dec + λ enc ​ ℒ enc , \mathcal{L}_{\mathrm{total}}=\lambda_{\mathrm{dec}}\mathcal{L}_{\mathrm{dec}}+\lambda_{\mathrm{enc}}\mathcal{L}_{\mathrm{enc}}, (10) where λ dec = λ enc = 1 \lambda_{\mathrm{dec}}=\lambda_{\mathrm{enc}}=1 . Synthetic pretraining. Starting from RF-DETR weights, we pretrain on procedural micrographs with exact centerline labels. The generator varies filament geometry, crossings, density, and image appearance, and includes empty fields. Procedural generation supplies diverse examples without additional manual tracing, providing supervision for learning filament shape and instance separation before adaptation to real data. Real data finetuning. The synthetic checkpoint initializes finetuning on annotated real micrographs. This stage uses the available centerline annotations to adapt the pretrained representation to specimen-specific filament morphology and experimental image appearance. Both stages use the same architecture and objective, with all parameters trainable. Data generation and preprocessing are specified in Appendix A ; optimization and checkpoint selection are specified in Appendix B . Inference and non-maximum suppression. At inference, we retain predictions with confidence at least 0.5 0.5 and apply polyline non-maximum suppression (NMS) to remove duplicate filament detections. Duplicates are identified by similar unoriented directions, substantial projected overlap, and small perpendicular separation, preserving the geometry of the higher-confidence curve. We use the same thresholds across both datasets and evaluation regimes (Appendix B.2 ). 4 Experiments We evaluate how accurately CryoTracer and established cryo-EM methods recover complete filaments on EMPIAR-10022 and α \alpha -synuclein. We use a 70/15/15% train/validation/test split in the standard regime. A typical reconstruction session contains about 2,000 micrographs, but experts may annotate only 30 to 50 to adapt a tracing model to a new specimen. We study this limited-annotation setting with a practical regime, using a 15/15/70% train/validation/test split. We report precision, recall, and F1 for filament detection, with Box IoU and coverage as complementary overlap metrics. We detail the splits, baseline configurations, and prediction conversions in Appendix B.3 . 4.1 Evaluation metrics We measure complete-instance recovery using orientation-invariant discrete Fréchet matching between predicted and annotated centerlines. Precision, recall, and F1 are computed per micrograph and averaged across the evaluation set. Matching is sensitive to fragmentation and endpoint errors. Our primary metric, mF1, averages these macro F1 scores equally over distance tolerances of 25 25 , 50 50 , 100 100 , 150 150 , and 200 200 Å. We compute mRecall and mPrecision by the same averaging procedure. Main results summarize five training seeds for confirmation, while ablations use only one seed. Appendix tables give per-tolerance scores and sample standard deviations. Box IoU and coverage provide complementary measures of spatial agreement between predicted and annotated filament regions. Pick counts and mean pick lengths in nanometres describe predictions and ground truth on the same evaluation images. We compare each variant with the main model in Table 3 . We describe the training changes in Appendix B.1 and report results at each matching tolerance in Appendix C . Synthetic initialization. With identical real-data partitions, 20,000 synthetic steps followed by 5,000 real-data steps yield standard-regime mF1 of 0.62 0.62 on EMPIAR-10022 and 0.44 0.44 on α \alpha -synuclein. Training directly from RF-DETR for 25,000 real-data steps gives 0.59 0.59 and 0.39 0.39 , respectively. The corresponding practical-regime scores are 0.53 0.53 and 0.36 0.36 with synthetic initialization, versus 0.40 0.40 and 0.11 0.11 for real-only training. The observed advantage is therefore larger in the practical regime. With only 5,000 real-only steps, mF1 is 0.16 0.16 and 0.18 0.18 in the standard regime and 0.07 0.07 and 0.02 0.02 in the practical regime. Synthetic initialization also improves spatial overlap relative to both real-only budgets. Real-data adaptation remains necessary, as the frozen synthetic-only model yields mF1 of 0.00 0.00 in all four settings. Curve supervision. Replacing Fréchet distance with Chamfer distance in both Hungarian matching and regression reduces standard-regime mF1 from 0.62 0.62 to 0.03 0.03 on EMPIAR-10022 and from 0.44 0.44 to 0.01 0.01 on α \alpha -synuclein after synthetic pretraining. Box IoU remains 0.71 0.71 and 0.69 0.69 , respectively. Substantial spatial overlap can therefore coexist with poor complete-instance agreement. This is consistent with Chamfer’s insensitivity to point order. Architecture. Restoring original RF-DETR box attention, while retaining five-point polyline outputs, lowers standard-regime mF1 to 0.57 0.57 on EMPIAR-10022 and 0.33 0.33 on α \alpha -synuclein, compared with 0.62 0.62 and 0.44 0.44 for the main model. Box IoU decreases to 0.82 0.82 and 0.69 0.69 , respectively. Reducing the feature pyramid from four levels to one lowers standard-regime mF1 from 0.62 0.62 to 0.56 0.56 on EMPIAR-10022 and from 0.44 0.44 to 0.36 0.36 on α \alpha -synuclein. Point-count effects vary by dataset. Three points score highest on EMPIAR-10022, whereas five score highest on α \alpha -synuclein. The simpler three-point representation may suit EMPIAR-10022’s relatively clean, straight filaments. However, its two line segments limit the representation of more strongly curved filaments, so this advantage may not generalize to more complex geometries. Ten points improve neither mF1 nor Box IoU over five. We find that synthetic pretraining followed by real-data adaptation improves mF1 over real-only training, with larger gains when annotations are limited. Our results also support Fréchet supervision, the modified attention design, and a four-level feature pyramid. Although the preferred point count depends on the dataset, we find five points to offer a reasonable compromise across the two datasets. 4.4 Limitations CryoTracer remains sensitive to ambiguous filament geometry. At crossings and overlaps, predicted traces can connect distinct filaments or recover only part of an instance. The fixed five-point representation may also limit the fidelity of traces with complex curvature. Synthetic pretraining reduces reliance on real training annotations but does not eliminate it. Our results cover two datasets with specimen-specific fine-tuning. Generalization to unseen specimens and acquisition conditions requires further evaluation. Replacing Fréchet distance with Chamfer distance in both Hungarian matching and regression reduces standard-regime mF1 from 0.62 0.62 to 0.03 0.03 on EMPIAR-10022 and from 0.44 0.44 to 0.01 0.01 on α \alpha -synuclein after synthetic pretraining. Box IoU remains 0.71 0.71 and 0.69 0.69 , respectively. Substantial spatial overlap can therefore coexist with poor complete-instance agreement. This is consistent with Chamfer’s insensitivity to point order. Architecture. Restoring original RF-DETR box attention, while retaining five-point polyline outputs, lowers standard-regime mF1 to 0.57 0.57 on EMPIAR-10022 and 0.33 0.33 on α \alpha -synuclein, compared with 0.62 0.62 and 0.44 0.44 for the main model. Box IoU decreases to 0.82 0.82 and 0.69 0.69 , respectively. Reducing the feature pyramid from four levels to one lowers standard-regime mF1 from 0.62 0.62 to 0.56 0.56 on EMPIAR-10022 and from 0.44 0.44 to 0.36 0.36 on α \alpha -synuclein. Point-count effects vary by dataset. Three points score highest on EMPIAR-10022, whereas five score highest on α \alpha -synuclein. The simpler three-point representation may suit EMPIAR-10022’s relatively clean, straight filaments. However, its two line segments limit the representation of more strongly curved filaments, so this advantage may not generalize to more complex geometries. Ten points improve neither mF1 nor Box IoU over five. We find that synthetic pretraining followed by real-data adaptation improves mF1 over real-only training, with larger gains when annotations are limited. Our results also support Fréchet supervision, the modified attention design, and a four-level feature pyramid. Although the preferred point count depends on the dataset, we find five points to offer a reasonable compromise across the two datasets. 4.4 Limitations CryoTracer remains sensitive to ambiguous filament geometry. At crossings and overlaps, predicted traces can connect distinct filaments or recover only part of an instance. The fixed five-point representation may also limit the fidelity of traces with complex curvature. Synthetic pretraining reduces reliance on real training annotations but does not eliminate it. Our results cover two datasets with specimen-specific fine-tuning. Generalization to unseen specimens and acquisition conditions requires further evaluation. The next step is to test whether improved filament recovery translates into more effective downstream classification and reconstruction. 5 Conclusion CryoTracer learns to trace individual cryo-EM filaments by predicting ordered centerline polylines, making geometry and instance identity explicit in the model output. The framework combines procedural synthetic pretraining, orientation-invariant Fréchet supervision, and specimen-specific fine-tuning. On EMPIAR-10022 and α \alpha -synuclein, it achieves higher complete-instance mF1 than Topaz and crYOLO in both standard and limited-annotation regimes, and outperforms the RELION Amyloid baseline on α \alpha -synuclein. Ablations support the value of synthetic initialization, with larger gains when real training annotations are scarce. Together with the overlap metrics, these results show why filament tracing should be evaluated for both spatial coverage and instance continuity. We release new EMPIAR-10022 centerline annotations to support further evaluation. Appendix B Training and evaluation details B.1 Training configuration Hardware and optimization. Each CryoTracer run uses one NVIDIA H100 GPU, bfloat16 mixed precision, gradient checkpointing, and a batch size of 64 micrographs. AdamW uses weight decay 10 − 4 10^{-4} and initial learning rates of 10 − 4 10^{-4} for the detector and 10 − 5 10^{-5} for the backbone. A cosine schedule decays both towards 10 − 6 10^{-6} over each stage, with gradient clipping at 1.0 1.0 . The complete model remains trainable throughout. Training stages and validation. Synthetic pretraining starts from RF-DETR weights adapted to single-channel input and runs for at most 20,000 steps, with validation every 500 steps. The selected synthetic model initializes dataset-specific fine-tuning for at most 5,000 steps, with validation every 100 steps on the corresponding real validation partition. Fine-tuning starts a new optimizer and learning-rate schedule. Within each seed, the same selected synthetic initialization is used for both real datasets and their standard and practical regimes. Checkpoint selection. At each stage, we retain the checkpoint minimizing the final decoder’s classification loss plus weighted polyline regression loss on the validation set. Encoder and intermediate decoder terms are excluded from this selection criterion. Final evaluation uses the selected real-data checkpoint. Test metrics do not influence model selection. Loss implementation. Batch regression losses are normalized by the total target count, clamped to at least one. Distributed training synchronizes this normalization across workers. Squared distances are floored at 10 − 12 10^{-12} before taking square roots. The hard minimum and maximum operations in the Fréchet recurrence are piecewise differentiable. Automatic differentiation follows the selected branches with the framework’s subgradient convention at ties. Reversal invariance applies to the objective, not to the decoder’s internal features. Ablation configurations. The ablation reference uses the main model’s configuration, including synthetic pretraining, Fréchet matching and regression, auxiliary decoder supervision, five polyline points, and a four-level feature pyramid. The no-synthetic condition starts directly from RF-DETR weights with a 5,000-step real-data training budget. Additional real-only controls train for 25,000 steps with the cosine schedule extended over that budget, matching the total optimizer steps of 20,000-step synthetic pretraining plus 5,000-step fine-tuning. These controls retain the same model, data partitions, and validation-selection criterion in both regimes. Optimizer-step matching does not imply identical wall time or computational cost. The Chamfer condition changes both matching and regression in pretraining and fine-tuning, using its own validation-selected synthetic initialization. The architecture ablations use three or ten polyline points, or a single feature-pyramid level. Each is pretrained and fine-tuned with the corresponding architecture. The original-attention ablation restores RF-DETR’s box-based deformable cross-attention and box positional encoding. At each decoder layer, the reference polyline supplies its axis-aligned enclosing box. This variant samples four locations per head and feature level, compared with four per polyline point (20 total) in the main model. It retains five-point outputs, polyline refinement and losses, and the four-level feature pyramid, using its own 20,000-step synthetic pretraining and 5,000-step real-data fine-tuning. The comparison therefore changes reference geometry, positional encoding, and sampling budget together. B.2 Inference and particle export Duplicate suppression. For filament evaluation, polyline NMS identifies duplicates using their unoriented directions, projected overlap relative to the shorter projected trace, and perpendicular separation. We use a 12 ∘ 12^{\circ} angular threshold, minimum overlap ratio 0.8 0.8 , and maximum separation 140 140 Å across both datasets and regimes. Suppression favors the higher-confidence curve and preserves its geometry. Fragments remain separate. RELION particle export. The optional export samples confidence-filtered curves uniformly by arc length, with physical spacing equal to the user-specified helical rise times the number of asymmetric units between samples. Centers whose extraction boxes would extend outside the micrograph are omitted. Each particle records its native coordinates, parent filament identifier, local tangent-angle prior, and cumulative distance along the original trace. Export-specific duplicate suppression and optional crossing exclusion operate on sampled particles. Removed samples leave gaps without resetting track distances. Filament identifiers restart within each micrograph. The resulting STAR file includes the associated optics and CTF metadata from the supplied micrographs STAR file and supports subsequent particle extraction in RELION. CryoTracer writes particle metadata, and RELION performs image extraction. B.3 Evaluation protocol Repeated runs and aggregation.
