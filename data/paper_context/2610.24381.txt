III Proposed Methodology We propose a class-conditioned explanation-guided learning framework for multi-label classification. For each positive class with an available spatial annotation, a class-specific explanation is generated and compared only with the annotations corresponding to that class. Explanatory evidence outside the corresponding annotated regions is penalized, and the resulting penalties are first averaged within each represented class and then across classes, preventing classes with more positive examples in an optimization step from receiving proportionally greater weight in the explanation objective. The complete training objective combines the conventional multi-label classification loss ( ℒ cls \mathcal{L}_{\mathrm{cls}} ) with the explanation loss ( ℒ exp \mathcal{L}_{\mathrm{exp}} ), shown in eq. 1 : ℒ total = ℒ cls + α ​ ℒ exp , \mathcal{L}_{\mathrm{total}}=\mathcal{L}_{\mathrm{cls}}+\alpha\mathcal{L}_{\mathrm{exp}}, (1) where α \alpha controls the strength of explanation guidance. A classifier f θ f_{\theta} produces one logit z n , c z_{n,c} for each of the K K classes: z n = f θ ​ ( x n ) , p n , c = σ ⁡ ( z n , c ) . z_{n}=f_{\theta}(x_{n}),\qquad p_{n,c}=\sigma(z_{n,c}). (3) Because multiple abnormalities may occur simultaneously, each class probability is modeled independently using a sigmoid output. III-B Class-Specific Explanation For each ground-truth-positive image–class pair ( n , c ) (n,c) with at least one valid spatial annotation, we construct an explanation specifically for class c c . This class-conditioned formulation is important in the multi-label setting because multiple abnormalities may occur in the same image. The explanation associated with one abnormality should therefore be supervised using only the spatial annotations corresponding to that abnormality. We instantiate the class-specific explanation using Grad-CAM. Let F n ∈ ℝ D × h × w F_{n}\in\mathbb{R}^{D\times h\times w} denote a spatial feature tensor for image n n , where D D is the number of feature channels and h × w h\times w is the spatial resolution. (4) The resulting class-specific heatmap is C n , c ​ ( i , j ) = ReLU ⁡ ( ∑ d = 1 D γ n , d ( c ) ​ F n , d , i , j ) . (5) Each heatmap is independently min–max normalized: C ¯ n , c ​ ( i , j ) = C n , c ​ ( i , j ) − min u , v ⁡ C n , c ​ ( u , v ) max u , v ⁡ C n , c ​ ( u , v ) − min u , v ⁡ C n , c ​ ( u , v ) + ϵ , \bar{C}_{n,c}(i,j)=\frac{C_{n,c}(i,j)-\min_{u,v}C_{n,c}(u,v)}{\max_{u,v}C_{n,c}(u,v)-\min_{u,v}C_{n,c}(u,v)+\epsilon}, (6) where the minimum and maximum are computed over the h × w h\times w spatial locations of the heatmap for the same image and class, and ϵ = 10 − 8 \epsilon=10^{-8} provides numerical stability. A separate heatmap is therefore obtained for every eligible positive class. For an image containing multiple abnormalities, the procedure produces multiple class-specific explanations rather than a single explanation shared across all positive labels. III-C Explanation Alignment Loss The spatial supervision for each explanation is constructed only from annotations belonging to the corresponding class. For a positive image–class pair ( n , c ) (n,c) , all valid annotations in ℛ n , c \mathcal{R}_{n,c} are mapped from the original image coordinate system to the preprocessed network input using the same aspect-preserving resize and padding transformation applied to the image. The transformed annotation boxes are then projected directly onto the native h × w h\times w resolution of the corresponding Grad-CAM feature map. The projected annotations for class c c are combined into a binary union mask M n , c ∈ { 0 , 1 } h × w M_{n,c}\in\{0,1\}^{h\times w} , whose entries are one at feature-grid cells lying inside any projected class- c c box and zero elsewhere. Multiple annotations for the same abnormality are therefore treated as a single spatial region through their union. Overlapping annotation boxes remain binary rather than being counted multiple times. Importantly, annotations belonging to another class do not contribute to M n , c M_{n,c} . Thus, when several abnormalities occur in the same image, the explanation for each class is evaluated only against the spatial annotations associated with that class. An annotation or bounding box marks where a finding is, but it is not an outline of it: an axis-aligned rectangle drawn around a lesion also encloses normal tissue. Requiring the explanation to fill the box would therefore teach the model to spread its evidence over healthy regions. We ask only that the evidence stay inside the box, and leave how it is distributed there free. Two steps implement this. First, we focus on the strongest part of the heatmap. After normalization, we retain saliency values greater than or equal to 0.5. Annotation boxes are often much larger than the finding itself, exact contours would allow a stricter setting. Second, the penalty for one image–class pair ( ℓ n , c \ell_{n,c} ) is the share of this retained evidence that falls outside the class- c c mask, as shown in eq. 7 . ℓ n , c = 1 − ∑ i , j G n , c ​ ( i , j ) ​ M n , c ​ ( i , j ) ∑ i , j G n , c ​ ( i , j ) . \ell_{n,c}=1-\frac{\sum_{i,j}G_{n,c}(i,j)\,M_{n,c}(i,j)}{\sum_{i,j}G_{n,c}(i,j)}. (7) It is zero when all retained evidence lies within the annotated region and grows as more of it falls outside. The explanation loss is evaluated only for ground-truth-positive image–class pairs that have at least one box. III-D Multi-Label Explanation Aggregation The penalty ℓ n , c \ell_{n,c} is computed for every positive image–class pair that carries an annotation. We average these penalties within each class first and then across the represented classes, so that each abnormality contributes equally instead of in proportion to how many annotated examples it happens to supply. The aggregated explanation loss is computed using eq. 8 . ℒ exp = 1 | 𝒞 | ​ ∑ c ∈ 𝒞 1 | ℐ c | ​ ∑ n ∈ ℐ c ℓ n , c , \mathcal{L}_{\mathrm{exp}}=\frac{1}{|\mathcal{C}|}\sum_{c\in\mathcal{C}}\frac{1}{|\mathcal{I}_{c}|}\sum_{n\in\mathcal{I}_{c}}\ell_{n,c}, (8) where 𝒞 \mathcal{C} is the set of those classes and ℐ c \mathcal{I}_{c} their annotated positive images. Setting α = 0 \alpha=0 in Eq. ( 1 ) recovers the classification-only baseline, and the explanation term is used only during training. The proposed objective requires a spatial feature representation for computing Grad-CAM. For EfficientNet-B1, we use the final convolutional feature map before global average pooling. For ViT-B/16 and ViT-B/32, the patch tokens entering the final transformer block are reshaped to their corresponding spatial grids after excluding the classification token. For Swin-B, we use the final-stage spatial feature representation. Because Grad-CAM channel weights are themselves gradients, differentiating the explanation objective through these weights requires second-order derivatives. We retain this gradient path for EfficientNet-B1. For ViT-B/16, ViT-B/32, and Swin-B, the Grad-CAM channel weights are treated as constants during explanation-loss backpropagation. The explanation loss therefore backpropagates through the selected spatial features but not through the gradient computation used to obtain the Grad-CAM channel weights. In all configurations, the classification loss follows the standard backpropagation path. IV Experimental Setup IV-A Dataset and Preprocessing We use the 15,000 images from VinDr-CXR [ 10 , 17 ] , which carry radiologist-provided bounding boxes for 14 abnormalities and a No finding category. We model the 14 abnormalities and retain No finding images as all-negative examples. Reader annotations are pooled, and multiple boxes for the same image–class pair are combined by union when constructing class-specific spatial masks. The dataset is divided into 12,000 training, 1,500 validation, and 1,500 test images, stratified by whether an image contains at least one modeled abnormality. Images are converted to three channels and resized with preserved aspect ratio and zero padding, with bounding boxes transformed accordingly. Random brightness and contrast augmentation of up to 15% is applied during training. EfficientNet-B1 and the ViTs use 1024 × 1024 1024\times 1024 inputs, while Swin-B uses 896 × 896 896\times 896 inputs. IV-B Training Protocol All models are trained with AdamW and mixed precision: EfficientNet-B1 for 50 epochs and the transformers for 30, with learning rates of 2 × 10 − 4 2\times 10^{-4} and 3 3 – 5 × 10 − 5 5\times 10^{-5} respectively. For each model, we train a classification-only baseline ( α = 0 \alpha=0 ) and explanation-guided models with α ∈ { 0.1 , 0.2 , … , 1.0 } \alpha\in\{0.1,0.2,\ldots,1.0\} , yielding 44 configurations. The checkpoint with the highest validation exact-match accuracy is used for test evaluation, with a classification threshold of 0.5. Each configuration is trained once; therefore, the reported results represent individual runs rather than estimates of variability across repeated training. Rows are the four best-supported classes; the left column shows the radiologist boxes in red, repeated in white on the model columns IV-C Evaluation Metrics Classification performance is evaluated on all 1,500 test images using exact-match accuracy, micro accuracy, micro precision, micro recall, micro-F1, macro-F1, and mean average precision (mAP). Exact match requires all 14 binary predictions for an image to be correct, while micro metrics pool decisions across classes. Macro-F1 averages class-wise F1 scores equally, and mAP is the unweighted mean of class-wise average precision computed from sigmoid probabilities. Because 1,060 of the 1,500 test images are all-negative, accuracy metrics are interpreted together with F1 and mAP. Localization is evaluated on all ground-truth-positive image–class pairs having at least one spatial annotation, giving 1,561 image–class pairs. Each class-specific Grad-CAM map is upsampled to the input resolution and independently normalized to [ 0 , 1 ] [0,1] . Following [ 20 ] , we report All-Saliency Precision (ASP), which measures the fraction of total saliency mass inside the corresponding class-specific annotation union, and Top-Saliency Precision (TSP), which measures the fraction of saliency thresholded at 0.5 that lies inside the annotation union. We additionally report annotation coverage, defined as the fraction of annotation boxes for which at least 1% of pixels have normalized saliency of at least 0.5. ASP and TSP are averaged over image–class pairs, whereas coverage is computed over the 3,647 individual test-set boxes. Localization is evaluated for every ground-truth-positive pair regardless of whether the corresponding class is predicted as present. We compare the classification-only baseline ( α = 0 \alpha=0 ) with the predefined maximum guidance setting ( α = 1 \alpha=1 ). V Results and discussion Figure 2 shows the per-epoch accuracy of the four guided models. All four fit the training set, reaching 0.90 0.90 – 0.99 0.99 exact-match accuracy, while validation accuracy plateaus near 0.73 0.73 – 0.75 0.75 ; the checkpoint retained for testing is the validation best in every case. V-A Overall Results Table I compares the classification-only baseline ( α = 0 \alpha=0 ) with the maximum guidance setting ( α = 1 \alpha=1 ). Explanation guidance substantially improves localization across all four configurations. ASP increases from 0.140 to 0.625 for EfficientNet-B1, 0.052 to 0.551 for ViT-B/16, 0.060 to 0.403 for ViT-B/32, and 0.095 to 0.570 for Swin-B. TSP shows the same overall pattern, while annotation coverage also increases, although by different amounts across models. The localization improvements are accompanied by smaller and architecture-dependent changes in classification performance. Micro-F1 changes from 0.690 to 0.692 for EfficientNet-B1, 0.617 to 0.654 for ViT-B/16, 0.632 to 0.618 for ViT-B/32, and 0.683 to 0.699 for Swin-B. Macro-F1 and mAP increase for three configurations but decrease slightly for ViT-B/32. Thus, explanation guidance consistently improves Grad-CAM alignment with the annotated regions, whereas its effect on classification performance is mixed. Figure 3 shows all eight metrics across the complete α \alpha sweep. Classification performance varies relatively little across most values of α \alpha . Micro-F1 remains within a range of approximately 0.02–0.04 across the guided settings for each model. Differences between architectures are generally larger than the changes observed across most values of α \alpha . The main exception is ViT-B/32 at α = 1 \alpha=1 , where micro precision decreases to 0.561, accompanied by lower micro accuracy and micro-F1. The localization metrics show a different pattern. Much of the ASP improvement occurs at the first nonzero guidance weight, increasing from 0.140 to 0.553 for EfficientNet-B1, 0.052 to 0.433 for ViT-B/16, 0.060 to 0.422 for ViT-B/32, and 0.095 to 0.446 for Swin-B. At larger values of α \alpha , the gains are more gradual, reaching maximum ASP values of 0.626, 0.562, 0.552, and 0.570, respectively. Swin-B shows a relatively smooth increase, whereas ViT-B/16 reaches most of its improvement at low α \alpha and ViT-B/32 fluctuates across the range. Coverage does not follow the same pattern as ASP; it is already relatively high for EfficientNet-B1 and Swin-B and decreases slightly for EfficientNet-B1 at some guidance strengths. This suggests that concentrating more saliency inside the annotated regions does not necessarily increase the number of annotated boxes reached by the explanation. Overall, localization responds strongly even at low explanation-guidance weights, while classification performance changes comparatively little across most of the sweep. V-B Class-Specific and Qualitative Results At the class level, ASP increases from α = 0 \alpha=0 to α = 1 \alpha=1 for most abnormalities across the four models, although this pattern is not consistent for all classes with ViT-B/16. These class-level results should be interpreted cautiously for abnormalities with limited test support; complete per-class ASP, F1, and support are provided in the supplementary material. Figure 4 follows one pair through the whole sweep for aortic enlargement using Swin-B architecture. Raising α \alpha pulls the evidence out of the surrounding thorax and into the annotated region. As shown in Table I , at α = 1 \alpha=1 , EfficientNet-B1 achieves the highest ASP (0.625) and TSP (0.681). Among the transformer models, Swin-B achieves the highest ASP (0.570), coverage, and micro-F1. Figure 5 shows four abnormalities across the four guided models, and guidance helps least where the box is far smaller than a Grad-CAM cell, as in the pulmonary-fibrosis and pleural-thickening rows, and where activation leaks onto the zero-padded border of the letterboxed input, which is the failure visible for Swin-B on cardiomegaly. Finally, the spatial annotations are pooled across readers, and both training and localization evaluation use Grad-CAM. Improvements in ASP and TSP therefore establish stronger alignment of these Grad-CAM explanations with class-specific annotations, but do not by themselves establish causal faithfulness, agreement with other attribution methods, or clinical validity. As Figure 5 shows, ASP is also sensitive to annotation scale: for abnormalities annotated with very small boxes it can report near-zero alignment for explanations that are visibly close to the correct structure, so per-class ASP should not be compared across classes whose boxes differ greatly in size. More broadly, these results show that explanation-guided learning can be extended to the multi-label setting without treating spatial supervision as a single annotation shared across all predictions. Preserving the correspondence between each abnormality and its own spatial annotations allows multiple class-specific explanations to be guided within the same image, while retaining a single joint multi-label classifier. The results across convolutional and transformer architectures further suggest that this formulation is not tied to a particular model family, although the spatial representation used to construct the explanation remains architecture dependent. This provides a practical basis for applying class-conditioned explanation guidance to other multi-label medical imaging problems where class-specific spatial annotations are available. VI Conclusion We presented a class-conditioned explanation-guided learning framework for multi-label chest X-ray classification, in which each positive class is guided by its corresponding spatial annotations. Across EfficientNet-B1, ViT-B/16, ViT-B/32, and Swin-B, explanation guidance substantially improved Grad-CAM alignment with annotated regions, with ASP increasing by 0.343–0.499 from α = 0 \alpha=0 to α = 1 \alpha=1 . These gains were accompanied by smaller, architecture-dependent changes in classification performance, with micro-F1 increasing in three of the four configurations. The results demonstrate that class-conditioned explanation guidance can improve where multi-label models concentrate their explanatory evidence while largely preserving predictive performance. Future work will evaluate repeated runs, additional datasets and attribution methods, and the clinical relevance and generalizability of the resulting explanations.
