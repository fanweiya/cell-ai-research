3.1 Architecture and Formulation AtomWorld-Mem follows a memory-centered principle: spatial encoders do not directly define the predictive state. Instead, they write high-information atomistic keyframes, and memory restores the missing evolutionary state by integrating these keyframes with past legal events. Space provides the instantaneous atomistic context, while memory converts partial observations into a future-predictive latent world state. Keyframe Writer. The Keyframe Writer converts the partial observation o t o_{t} in Eq. ( 4 ) into a compact spatial keyframe. It uses two complementary spatial pathways: h t dense = f gnn ( G t local ) , h t sparse = f attn ( S t def ) , k t = ϕ fuse ( [ h t dense ∥ h t sparse ] ) . h_{t}^{\mathrm{dense}}=f_{\mathrm{gnn}}(G_{t}^{\mathrm{local}}),\qquad h_{t}^{\mathrm{sparse}}=f_{\mathrm{attn}}(S_{t}^{\mathrm{def}}),\qquad k_{t}=\phi_{\mathrm{fuse}}([h_{t}^{\mathrm{dense}}\|h_{t}^{\mathrm{sparse}}]). (10) The dense pathway captures short-range topology that determines immediate legal transitions, while the sparse pathway captures long-range defect context that shapes slower structural evolution. The keyframe k t k_{t} is not treated as a complete state; it is a spatial write into memory that must be interpreted together with past evolution. Latent-State Memory. The Latent-State Memory restores hidden evolutionary context by integrating spatial keyframes with previous legal events, following the state-restoration view in Eq. ( 6 ). We decompose this restoration into two temporal scales. The short-term event memory summarizes recent action history and local transition competition: c t short = ϕ hist ( ϕ act ( a t − H : t − 1 ) ) . c_{t}^{\mathrm{short}}=\phi_{\mathrm{hist}}\!\left(\phi_{\mathrm{act}}(a_{t-H:t-1})\right). (11) It captures recent vacancy motion, local reversibility, repeated back-and-forth exchanges, and short-horizon competition among nearby legal events. The long-term structural memory accumulates slower evolutionary biases: m t long = f rnn ( m t − 1 long , [ k t ∥ c t short ] ) . m_{t}^{\mathrm{long}}=f_{\mathrm{rnn}}\!\left(m_{t-1}^{\mathrm{long}},[k_{t}\|c_{t}^{\mathrm{short}}]\right). (12) This recurrent state retains hidden defect-evolution trends, aggregation tendency, vacancy–solute interaction patterns, and structural biases over many KMC steps. The restored world state is obtained by combining instantaneous space, short-term event context, and long-term structural memory: z t = ϕ mem ​ ( [ k t ​ ‖ c t short ‖ ​ m t long ] ) . z_{t}=\phi_{\mathrm{mem}}\!\left([k_{t}\|c_{t}^{\mathrm{short}}\|m_{t}^{\mathrm{long}}]\right). (13) Thus, z t z_{t} is not merely an encoding of the current observation; it is a memory-restored latent state used for both future event preference and time-scale reasoning. Legal Event Scorer.
