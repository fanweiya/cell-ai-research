2 Generalized patch-based compressive sensing model In this section, we first introduce a patch-based CS model that generalizes many traditional patch-based models. By introducing auxiliary variables via a penalty function, we apply the BCD algorithm to solve this model. In Section 3 , we further derive the corresponding network architecture of PE-CSNet by unrolling and generalizing the BCD algorithm. 2.1 Model While patch-based regularization is widely used in model-driven CS, many such methods can be summarized in the following general form [ 40 , 46 , 47 , 60 , 51 ] : 𝒙 ^ = arg ⁡ min 𝒙 ​ { 1 2 ‖ Φ ​ 𝒙 − 𝒚 ∥ 2 2 + λ ​ ∑ i , j ‖ Ψ ​ ( D i ​ j ​ 𝒙 ) ‖ 1 } , \hat{\boldsymbol{x}}=\underset{\boldsymbol{x}}{\arg\min}\left\{\dfrac{1}{2}\|\Phi\boldsymbol{x}-\boldsymbol{y}\|_{2}^{2}+\lambda\sum_{i,j}\|\Psi(D_{ij}\boldsymbol{x})\|_{1}\right\}, (2.1) where Ψ \Psi is a (typically predefined) sparsifying transform of the ( i , j ) (i,j) -th patch of x x and λ > 0 \lambda>0 is the regularization parameter. The transform Ψ \Psi in ( 2.1 ) includes common choices such as wavelet transforms [ 46 , 47 ] , learned dictionaries [ 60 ] . Note that the patch-based CS model ( 2.1 ) is a special case of ( 1.1 ) that focuses on patch-based transform sparsity. To better exploit the a priori information within image patches, we generalize the model in ( 2.1 ) by replacing the sparsifying transform Ψ \Psi and the ℓ 1 \ell_{1} penalty with a more general regularizer. The generalized patch-based CS model can be formulated as follows: 𝒙 ^ = arg ⁡ min 𝒙 ​ { 1 2 ‖ Φ ​ 𝒙 − 𝒚 ∥ 2 2 + ∑ i , j ℛ ​ ( D i ​ j ​ 𝒙 ) } , \hat{\boldsymbol{x}}=\underset{\boldsymbol{x}}{\arg\min}\left\{\dfrac{1}{2}\|\Phi\boldsymbol{x}-\boldsymbol{y}\|_{2}^{2}+\sum_{i,j}\mathcal{R}(D_{ij}\boldsymbol{x})\right\}, (2.2) where ℛ \mathcal{R} is a (possibly) nonlinear regularization function that enforces sparsity on the extracted patches. We note that the regularization parameter λ \lambda is absorbed into the definition of ℛ \mathcal{R} . Notably, the previous model ( 2.1 ) is a special case of our generalized model ( 2.2 ), with ℛ ​ ( ⋅ ) := λ ​ ‖ Ψ ​ ( ⋅ ) ‖ 1 \mathcal{R}(\cdot):=\lambda\|\Psi(\cdot)\|_{1} . In contrast to traditional model-driven methods where ℛ \mathcal{R} is predefined, our approach determines ℛ \mathcal{R} via an end-to-end learning strategy. 2.2 BCD solver The BCD algorithm provides an efficient solver for the generalized patch-based model ( 2.2 ), owing to its separable structure across patches. To apply the BCD algorithm, we first employ the variable splitting and quadratic penalty technique [ 47 , 57 ] to the CS model ( 2.2 ). By introducing an auxiliary variable 𝒛 \boldsymbol{z} in the image domain, we convert ( 2.2 ) into the constrained form: min 𝒙 , 𝒛 ​ { 1 2 ‖ Φ ​ 𝒙 − 𝒚 ∥ 2 2 + ∑ i , j ℛ ​ ( D i ​ j ​ 𝒛 ) } , s.t. ​ 𝒛 = 𝒙 . \underset{\boldsymbol{x},\boldsymbol{z}}{\min}\left\{\dfrac{1}{2}\left\|\Phi\boldsymbol{x}-\boldsymbol{y}\right\|_{2}^{2}+\sum_{i,j}\mathcal{R}(D_{ij}\boldsymbol{z})\right\},\quad\textit{s.t.}\;\boldsymbol{z}=\boldsymbol{x}. (2.3) Applying the quadratic penalty technique, we obtain a relaxed unconstrained version of ( 2.3 ) as follows: ℒ ​ ( 𝒙 , 𝒛 ; ρ ) := 1 2 ​ ‖ Φ ​ 𝒙 − 𝒚 ‖ 2 2 + ∑ i , j ℛ ​ ( D i ​ j ​ 𝒛 ) + ρ 2 ​ ‖ 𝒙 − 𝒛 ‖ 2 2 , \mathscr{L}(\boldsymbol{x},\boldsymbol{z};\rho):=\dfrac{1}{2}\|\Phi\boldsymbol{x}-\boldsymbol{y}\|_{2}^{2}+\sum_{i,j}\mathcal{R}(D_{ij}\boldsymbol{z})+\dfrac{\rho}{2}\|\boldsymbol{x}-\boldsymbol{z}\|_{2}^{2}, (2.4) where ρ > 0 \rho>0 is the penalty factor. To minimize ( 2.4 ), we use the BCD, which alternately updates 𝒙 \boldsymbol{x} and 𝒛 \boldsymbol{z} by solving the following subproblems: { arg ⁡ min 𝒙 ​ 1 2 ​ ‖ Φ ​ 𝒙 − 𝒚 ‖ 2 2 + ρ 2 ​ ‖ 𝒙 − 𝒛 ‖ 2 2 , arg ⁡ min 𝒛 ​ ∑ i , j ℛ ​ ( D i ​ j ​ 𝒛 ) + ρ 2 ​ ‖ 𝒙 − 𝒛 ‖ 2 2 . \left\{\begin{array}[]{ll}\underset{\boldsymbol{x}}{\arg\min}\;\dfrac{1}{2}\|\Phi\boldsymbol{x}-\boldsymbol{y}\|^{2}_{2}+\dfrac{\rho}{2}\|\boldsymbol{x}-\boldsymbol{z}\|^{2}_{2},\\ \underset{\boldsymbol{z}}{\arg\min}\;\sum_{i,j}\mathcal{R}(D_{ij}\boldsymbol{z})+\dfrac{\rho}{2}\|\boldsymbol{x}-\boldsymbol{z}\|_{2}^{2}.\end{array}\right. (2.5) Since ‖ 𝒙 − 𝒛 ‖ 2 2 = ∑ i , j ‖ D i ​ j ​ 𝒙 − D i ​ j ​ 𝒛 ‖ 2 2 \|\boldsymbol{x}-\boldsymbol{z}\|_{2}^{2}=\sum_{i,j}\|D_{ij}\boldsymbol{x}-D_{ij}\boldsymbol{z}\|_{2}^{2} , the 𝒛 \boldsymbol{z} -subproblem above can be decoupled as follows: arg ⁡ min D i ​ j ​ 𝒛 ​ ℛ ​ ( D i ​ j ​ 𝒛 ) + ρ 2 ​ ‖ D i ​ j ​ 𝒙 − D i ​ j ​ 𝒛 ‖ 2 2 , ∀ i , j . \underset{D_{ij}\boldsymbol{z}}{\arg\min}\;\mathcal{R}(D_{ij}\boldsymbol{z})+\dfrac{\rho}{2}\|D_{ij}\boldsymbol{x}-D_{ij}\boldsymbol{z}\|_{2}^{2},\quad\forall i,j. Let I I denote the identity operator, with the dimension understood from context. Then, the subproblems of ( 2.5 ) admit the following closed-form updates: { 𝑿 ( n ) : 𝒙 ( n ) = ( Φ H ​ Φ + ρ ​ I ) − 1 ​ [ Φ H ​ 𝒚 + ρ ​ 𝒛 ( n − 1 ) ] , ⋯ ​ ⋯ 𝒁 i ​ j ( n ) : D i ​ j ​ 𝒛 ( n ) ∈ prox ( 1 / ρ ) ​ ℛ ​ ( D i ​ j ​ 𝒙 ( n ) ) , ⋯ ​ ⋯ \left\{\begin{array}[]{ll}\boldsymbol{X}^{(n)}:\boldsymbol{x}^{(n)}=(\Phi^{H}\Phi+\rho I)^{-1}[\Phi^{H}\boldsymbol{y}+\rho\boldsymbol{z}^{(n-1)}],\\ \cdots\cdots\\ \boldsymbol{Z}^{(n)}_{ij}:D_{ij}\boldsymbol{z}^{(n)}\in\mathrm{prox}_{(1/\rho)\mathcal{R}}(D_{ij}\boldsymbol{x}^{(n)}),\\ \cdots\cdots\end{array}\right. (2.6) where prox ( 1 / ρ ) ​ ℛ ​ ( ⋅ ) \mathrm{prox}_{(1/\rho)\mathcal{R}}(\cdot) is the proximal operator of ℛ \mathcal{R} with parameter 1 / ρ 1/\rho , and the superscript H H denotes Hermitian transpose. Here, 𝒛 ( n ) \boldsymbol{z}^{(n)} can be obtained by reassembling its patches D i ​ j ​ 𝒛 ( n ) D_{ij}\boldsymbol{z}^{(n)} , i.e., 𝒛 ( n ) = 𝚁𝚎𝚊𝚜𝚜𝚎𝚖𝚋𝚕𝚎 ​ ( { D i ​ j ​ 𝒛 ( n ) } ) \boldsymbol{z}^{(n)}=\mathtt{Reassemble}(\{D_{ij}\boldsymbol{z}^{(n)}\}) (see Section 1 ). Note that the regularization function ℛ \mathcal{R} in ( 2.2 ) encodes the patch-based sparse a priori information, which is unknown and difficult to choose in advance. Consequently, its proximal operator prox ( 1 / ρ ) ​ ℛ \mathrm{prox}_{(1/\rho)\mathcal{R}} lacks an explicit, implementable form. To address this, we approximate the proximal operator via a deep neural network, which is achieved by unrolling and generalizing the BCD iterations derived above into a learnable architecture, as detailed in the next section. Remark 2.1 . Suppose that for each ρ ( k ) \rho^{(k)} , the pair ( 𝐱 k , 𝐳 k ) (\boldsymbol{x}_{k},\boldsymbol{z}_{k}) is an exact minimizer of ℒ ​ ( 𝐱 , 𝐳 ; ρ ( k ) ) \mathscr{L}(\boldsymbol{x},\boldsymbol{z};\rho^{(k)}) defined in ( 2.4 ), and that ρ ( k ) → ∞ \rho^{(k)}\to\infty . It is known from [ 45 , Chapter 17.1] that every limit point of { ( 𝐱 k , 𝐳 k ) } \{(\boldsymbol{x}_{k},\boldsymbol{z}_{k})\} is a solution to ( 2.3 ). Therefore, solving ( 2.4 ) with sufficiently large ρ \rho provides a reasonable approximation to the exact solution of ( 2.3 ). This justifies our use of ( 2.4 ). Remark 2.2 . The update for 𝐱 \boldsymbol{x} in ( 2.6 ) requires solving a linear system involving ( Φ H ​ Φ + ρ ​ I ) (\Phi^{H}\Phi+\rho I) , which can be computationally expensive for general measurement matrices. In this work, we focus on structurally random matrices (SRMs) [ 19 ] —such as partial Fourier matrices or coded diffraction patterns (CDPs) [ 35 ] —which are widely used in CS. For these SRMs, the linear system in ( 2.6 ) can be solved efficiently using a closed-form solution [ 57 ] , which we use in our implementation. 2.1 Model While patch-based regularization is widely used in model-driven CS, many such methods can be summarized in the following general form [ 40 , 46 , 47 , 60 , 51 ] : 𝒙 ^ = arg ⁡ min 𝒙 ​ { 1 2 ‖ Φ ​ 𝒙 − 𝒚 ∥ 2 2 + λ ​ ∑ i , j ‖ Ψ ​ ( D i ​ j ​ 𝒙 ) ‖ 1 } , \hat{\boldsymbol{x}}=\underset{\boldsymbol{x}}{\arg\min}\left\{\dfrac{1}{2}\|\Phi\boldsymbol{x}-\boldsymbol{y}\|_{2}^{2}+\lambda\sum_{i,j}\|\Psi(D_{ij}\boldsymbol{x})\|_{1}\right\}, (2.1) where Ψ \Psi is a (typically predefined) sparsifying transform of the ( i , j ) (i,j) -th patch of x x and λ > 0 \lambda>0 is the regularization parameter.
